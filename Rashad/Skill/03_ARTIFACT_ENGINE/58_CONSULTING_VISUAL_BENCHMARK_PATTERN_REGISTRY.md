# Consulting Visual Benchmark Pattern Registry

STATUS: ACTIVE ABSTRACT BENCHMARK REGISTRY
SOURCE: existing audited historical-proposal intelligence + current Rashad Artifact Intelligence. No raw historical asset is production authority.

Use this registry to compare **quality and analytical structure**, never to clone exact layouts.

| ID | Benchmark page/artifact pattern | Use when | Quality signal | Weak substitute to reject |
|---|---|---|---|---|
| BMR-01 | Executive thesis + decision signals | senior decision must be made quickly | one focal thesis, evidence-backed signals, explicit action | decorative KPI cards |
| BMR-02 | Client need → objective → outcome chain | RFP language mixes needs and activities | clear causal progression and success implication | paraphrased scope bullets |
| BMR-03 | Strategic pillar / north-star architecture | several themes converge on one outcome | hierarchy and integrated logic | independent pillars/cards |
| BMR-04 | Scope system / workstream architecture | scope items interact | dependencies and interfaces visible | list of scope items |
| BMR-05 | Phase journey with gates | implementation moves through stages | outputs, approvals and gates visible | decorative timeline |
| BMR-06 | Multi-track delivery architecture | parallel tracks share milestones | cross-track dependency and integration | swimlanes with no relationships |
| BMR-07 | BOQ compression & acceptance architecture | broad scope compressed into few commercial lines | scope→BOQ→deliverable→acceptance→cost logic | raw BOQ table only |
| BMR-08 | Technical / data / integration architecture | systems/data/AI/integration requirements are material | constraints, interfaces and dependencies explicit | technology logo wall |
| BMR-09 | Team capacity / role-to-output model | staffing drives delivery risk | quantity, capability, ownership and outputs connected | biographies or role cards |
| BMR-10 | Criteria-to-win architecture | evaluation scoring determines proposal strategy | criterion→evidence→response→differentiation→risk | detached percentages |
| BMR-11 | Qualification / evidence readiness matrix | bid eligibility/evidence gaps matter | status, owner, deadline and bid impact visible | document inventory |
| BMR-12 | Commercial exposure architecture | pricing uncertainty is material | cost drivers, dependencies, assumptions and confidence linked | price-driver bullet list |
| BMR-13 | Proposal build-priority map | pursuit team needs action | dependencies, workstreams, proof gaps and lock points | generic action list |
| BMR-14 | Proposal preparation critical-path Gantt | submission deadline drives work | parallel tracks, gates, review cycles and buffer visible | sequential checklist |
| BMR-15 | Contract delivery roadmap | execution plan needs time logic | phases, deliverables, gates, approvals and support/handover | broad month labels only |
| BMR-16 | Risk prioritization & response model | multiple material bid/delivery risks | cause/event/impact/trigger/mitigation/owner | generic risk cards |
| BMR-17 | Strategic clarification decision register | unknowns change scope/price/solution | question→decision changed→impact→assumption | procurement-obvious questions |
| BMR-18 | Assumption / information-gap architecture | unresolved evidence must be managed | gap→assumption→impact→validation owner | narrative caveats |
| BMR-19 | Authorship / procurement-maturity diagnostic | package consistency affects uncertainty | evidence for/against, maturity dimensions, pricing/delivery implication | subjective “weak RFP” label |
| BMR-20 | Governance & decision architecture | ownership/escalation matters | decision rights, cadence, escalation and information flow | org chart only |
| BMR-21 | Case-study proof architecture | experience must support current criterion | claim→evidence→observable outcome→relevance | screenshot/certificate wall |
| BMR-22 | Stakeholder ecosystem / alignment map | multiple actors influence success | role, flow, influence or interface encoded | logo wall |
| BMR-23 | Current-to-target transformation | change from present to future is central | diagnosed gap connected to target capabilities and transition | before/after decoration |
| BMR-24 | Management / bid decision cockpit | final GO/HOLD/NO-GO decision required | attractiveness, win, delivery, evidence, pricing, conditions and blockers | repeat of executive summary |

## Benchmark comparison record
For each critical page, store:
- page role;
- selected BMR ID(s);
- what quality attributes are being compared;
- where new page is stronger/equal/weaker;
- hard weaknesses;
- redesign instruction if below floor.

## Non-cloning rule
Do not copy historical page coordinates, styling, logo, colors, text, client facts, screenshots, or proprietary content. The registry represents only abstract consulting visual intelligence.

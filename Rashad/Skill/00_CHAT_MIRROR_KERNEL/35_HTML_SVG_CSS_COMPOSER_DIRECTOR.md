# HTML/SVG/CSS Composer Director

STATUS: PRIMARY VISUAL COMPOSITION DIRECTOR — v2.6.4.9

## Production master
The default final visual master is a fixed 16:9 HTML artboard using:
- semantic HTML for text and structure;
- CSS Grid/Flex for macro zones;
- inline SVG for connectors, paths, rings, matrices, timelines, Gantts, maps, networks, systems and relationship geometry;
- governed raster/vector assets for photography, logos and illustrations.

## Composer behavior
The composer reproduces the **approved visual concept**, not a generic component library.

Cards may appear as subcomponents, but the page architecture must come from the higher-order artifact: system, journey, matrix, architecture, network, cockpit, value chain, roadmap, governance or decision logic.

## Fixed-canvas rule
Use a deterministic 16:9 canvas (normally 1920×1080 equivalent). No responsive reflow for production export.

## Output route
`HTML/SVG/CSS → browser raster → visual critique/repair → approved HTML master → PDF + PPTX visual mirror`.

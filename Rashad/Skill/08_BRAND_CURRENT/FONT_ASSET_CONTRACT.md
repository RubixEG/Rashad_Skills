# Font Asset Contract — v6.2

**STATUS: CURRENT ASSET TRUTHFULNESS CONTRACT**

This Skill package does **not** ship font binary files. Exact typography is permitted only when the runtime verifies externally supplied/licensed font assets or an owner-approved fallback.

Runtime evidence should record requested family, resolved family, file/source provenance where permitted, load success, fallback status and rendered measurement. If an exact required family is unavailable, do not claim typographic parity.

Never embed, redistribute or invent proprietary font binaries inside the Skill package.

# Isolated Visual Asset & Production Admission Workflow

STATUS: v2.6.4.3 ACTIVE WORKFLOW

`Page Contract → Visual Need? → Isolated Asset Brief → Generation → Asset Admission QA → APPROVED_AS_VISUAL_INGREDIENT → Canonical Page Scene Graph → Deterministic Composer → Machine QA → Council Release`

If generation produces slide/document chrome, text, numerals, logos, tables/cards, or final analytical topology: `REJECTED_CONTAMINATED`; do not feed it downstream as production.

If deterministic composer/runtime evidence is unavailable: stop at approved spec/assets and mark production release BLOCKED.

# HTML/CSS Production Style System

## Typography
Use native, direction-safe text. Maintain a clear scale hierarchy across title, thesis, artifact labels, body copy, metrics, callouts and footers.

## Surfaces
Primarily white/off-white. Use subtle tints for grouping and strong color only for analytical emphasis.

## Lines / borders
Favor hairlines, deliberate separators and SVG connectors over heavy boxed borders.

## Radius
Rounded corners are restrained and functional; do not apply large rounded rectangles to every object.

## Shadows
Minimal / near-none. Avoid SaaS-dashboard elevation styling.

## Illustration
Editorial photography or purpose-built visual assets may support a page, but analytical pages should not use decorative imagery as a substitute for argument.

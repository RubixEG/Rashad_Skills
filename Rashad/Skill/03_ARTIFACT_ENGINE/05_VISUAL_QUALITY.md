# Visual Quality Standard
> **v2.2 USER AUTHORITY — BLOCKING:** For Arabic client-facing natural-language content, use Arabic-Indic numerals `٠١٢٣٤٥٦٧٨٩`. Any older instruction in this file to follow Western RFP digits for Arabic prose is superseded. Preserve raw Western digits only in exact technical/machine/reference identifiers that cannot safely change. `01_ACTIVE_RUNTIME/29_PRODUCTION_EXECUTION_FIREWALL.md` governs release.


## Numeral authority override — current rule
Current user override supersedes historic source-following numeral heuristics for Arabic natural-language output. Arabic-Indic numerals are mandatory in Arabic prose; exact technical/machine/reference identifiers remain raw when necessary for correctness. Generated imagery never decides numeral style.


## Quality dimensions
- strong page thesis;
- clear focal point;
- correct relationship-to-visual mapping;
- balanced density;
- consistent alignment axes;
- purposeful iconography and imagery;
- current identity purity;
- native RTL reading order;
- readable text sizes;
- source and page navigation consistency;
- editable construction.

## Hard fails
- text behind text or shapes;
- clipping or overflow;
- wrong logo or generated logo;
- Western numeral leakage inside Arabic natural-language content;
- item ١ starting on the left;
- footer collision;
- page rendered as a screenshot only;
- generic blue Word-document styling;
- decorative visualization without analytical purpose.

## v7.6 strength hard fails
- safe but materially weaker than the approved benchmark;
- generic-card fallback replacing the correct relationship;
- repeated composition family beyond the allowed rhythm;
- unsupported visual encoding that implies unverified severity, maturity, readiness, or weight;
- failure to call the Visual Asset Decision Engine.

## v2.3 artifact-intelligence quality layer
Visual quality is evaluated against the approved Artifact Intent and Visual Blueprint, not against aesthetic preference alone. A page that is attractive but loses semantic nodes/edges, reading path, RTL order, editability, or evidence fidelity is a failure. Apply `31_ARTIFACT_DIVERSITY_AND_RHYTHM.md` and `33_ARTIFACT_ENGINE_ACCEPTANCE_TESTS.md`.

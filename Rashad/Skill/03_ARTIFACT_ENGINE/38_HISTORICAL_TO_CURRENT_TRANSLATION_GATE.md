# Historical-to-Current Translation Gate

Any idea learned from a historical proposal must pass all gates:

1. **Argument extraction:** identify the page/sequence argument without relying on historical visual skin.
2. **Relationship classification:** sequence, hierarchy, dependency, system, comparison, evidence, timeline, decision, etc.
3. **Abstract archetype:** choose/create a current Rashad archetype; do not use an exact historical template.
4. **Fact reset:** remove all historical client/project facts.
5. **Brand reset:** remove historical logo/colors/fonts/footer/master.
6. **Language reset:** current engagement language only.
7. **Artifact Intent:** current thesis/evidence/nodes/edges defined.
8. **Current Visual Blueprint:** rebuilt for the current page.
9. **Current Rubix Brand:** applied only after topology is stable.
10. **Production Firewall + QA:** exact current assets, RTL, numerals, no dark/black violation.

Failure at any gate means `REFERENCE_REJECTED_FOR_PRODUCTION`.

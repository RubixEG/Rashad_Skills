# External Appendix & Evidence Contract

## Core rule
The portable Rashad core contains **no appendix PDF, CV PDF, certificate scan, client logo, CV photo, or historical case-study binary**.

Evidence is supplied per environment/engagement as an external package and indexed at runtime.

## Expected external categories
- CVs / team credentials
- case studies / reference projects
- registrations / certificates / licences
- company documents
- project-specific client assets

## Runtime process
`discover → inventory → validate provenance → deduplicate → check expiry/availability/confidentiality → match to current RFP → shortlist → human/owner approval → render selected evidence`.

## Hard rules
Presence ≠ compliance. Presence ≠ validity. Presence ≠ availability. Never invent missing evidence.


## v6.2 readiness truth
The core package intentionally does not contain the external evidence binaries. Any page/claim requiring CVs, case studies, certifications, licences, registrations, or client assets must record the mount/readiness state. Missing evidence is `MISSING_EXTERNAL_EVIDENCE` and cannot be replaced by model invention.

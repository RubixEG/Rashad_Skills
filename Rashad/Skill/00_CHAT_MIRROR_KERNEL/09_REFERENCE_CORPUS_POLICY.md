# Reference Corpus Policy — Behavioral Mirror

STATUS: ACTIVE

## Historical proposals
Every historical proposal is reference-only visual/narrative research regardless of how modern it appears.

May teach:
- consulting storytelling;
- argument structure;
- information relationships;
- evaluator navigation;
- narrative/page rhythm;
- density management;
- methodology/deliverable/governance/team/case-study communication patterns.

Must never supply:
- current logo or sub-brand selection;
- current colors/fonts/theme;
- exact historical page coordinates/layouts;
- historical client facts/images/prices/team data;
- current company facts;
- current production template authority.

## Generated visual corpus
Generated examples may teach visual hierarchy/composition/archetype behavior only. Generated text/logo/numeral behavior is never production authority.

## Current design authority
Only the current verified Rubix brand/deck authorities and embedded current assets govern production identity.

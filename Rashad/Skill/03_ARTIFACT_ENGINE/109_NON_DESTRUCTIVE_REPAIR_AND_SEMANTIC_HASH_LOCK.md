# Non-Destructive Repair & Semantic Hash Lock

Before repair, freeze:
- content signature;
- node set;
- edge set;
- label set;
- topology signature;
- brand asset signature;
- direction signature;
- Golden Master fidelity signature.

Allowed repair order:
1. line-break optimization;
2. local spacing changes;
3. local region expansion/rebalance;
4. connector reroute;
5. secondary annotation movement;
6. page split where needed.

Forbidden repair:
- delete evidence/content;
- remove node/edge/label;
- change artifact family;
- convert system/journey/network to generic cards;
- globally shrink text below minimum;
- hide/clip content;
- reverse RTL/LTR semantics;
- alter approved logos/assets.

After repair, all semantic hashes/signatures must match except geometry-approved fields.

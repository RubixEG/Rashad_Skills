# Section-Level Golden Board Workflow

STATUS: ACTIVE ADDITIVE WORKFLOW

## Objective
Create the section as one coherent visual argument before native page construction, while keeping generated imagery reference-only and production-safe.

## Workflow
1. Complete the applicable product/role Depth Contract.
2. Expand the role/section into the number of pages required by evidence and analytical relationships.
3. Complete page Question, Thesis, Evidence, Relationship, Artifact Intent, Nodes/Edges and preliminary Blueprint for every page.
4. Run the Section Visual Board Director.
5. Generate one Golden Section Board for 2–8 related pages in a single visual generation request.
6. Reject the board if it contains readable text, logos, numbers, client facts, wrong brand marks, or weak/repetitive composition.
7. Approve a Section Visual Charter and page visual targets.
8. Convert each target into deterministic Geometry Handoff. Do not reinterpret the layout freely.
9. Compose native Arabic text, exact data, tables, logos, connectors, and assets.
10. Render HTML/PDF/PPTX projections from the same approved visual model.
11. Run page parity and section-level parity against the Golden Section Board.
12. Repair geometry or typography without changing artifact topology.
13. Release only after Content QA + Artifact QA + Visual Fidelity QA + Brand/RTL QA pass.

## Cover exception
The cover uses its dedicated competition-specific hero generation flow and is not grouped into a Section Golden Board.

## Failure behavior
If a generated board is strong but the native reconstruction is weak, the correct response is **not** to accept the native simplification. Rebuild the native geometry to preserve the approved board. If a deterministic reconstruction cannot preserve the board, report the production limitation instead of silently downgrading.
## v2.6.4.1 two-key extension
After approving the Golden Section Board / page visual targets, run the Consulting Visual Excellence & Ministry Gate before deterministic geometry is released. After HTML/PDF/PPTX rendering, run Rendering Stress QA, Artifact Integrity, RTL/brand and cross-format parity. The board is not permission for a renderer to reinterpret or simplify page topology.

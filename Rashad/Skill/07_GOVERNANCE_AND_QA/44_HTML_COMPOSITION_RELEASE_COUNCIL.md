# HTML Composition Release Council

A page may proceed to export only when:
- approved visual concept is traceable;
- browser screenshot matches the intended composition;
- CVFS threshold is met;
- content density contract is met;
- applicable QA Harness gates pass;
- co-brand / RTL / typography pass;
- no card-only fallback or color drift exists;
- HTML master is frozen/hash-linked.

# Palette and Color Discipline Governor

Rashad must not allow uncontrolled multi-color drift.

Hard rules:
- white/off-white base is the primary canvas;
- black/charcoal are the primary text/structure tones;
- Rubix magenta is the main accent;
- use one muted support color only when analytically necessary;
- extra accent colors require semantic justification and approval;
- color is for hierarchy, emphasis, and differentiation — never for decoration.

Block output when:
- the page uses many bright accents without analytical reason;
- the page looks more like a marketing infographic than a consulting deck;
- the model invents palette variety unsupported by the deck DNA.

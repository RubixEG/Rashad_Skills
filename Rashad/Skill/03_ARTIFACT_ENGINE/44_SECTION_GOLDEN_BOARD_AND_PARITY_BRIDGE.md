# Section Golden Board & Visual Parity Bridge

STATUS: HARD ARTIFACT EXECUTION AUTHORITY

## Problem addressed
A generated visual concept can look substantially stronger than the later HTML/PDF result when the handoff captures only semantic intent and the composer independently redesigns the page. That is a lossy semantic-to-layout transformation.

The fix is not to use the generated board as the final page. The fix is to preserve its approved **visual topology** during native reconstruction.

## Canonical section pipeline
`Evidence → Role Depth Contract → Page Questions → Theses → Relationships → Artifact Intents → Nodes/Edges → Preliminary Blueprints → Golden Section Board → Section Visual Charter → Frozen Page Visual Targets → Native Geometry → Composer → Render → Visual Parity QA → Repair → Release`

The Golden Section Board is downstream of analysis and upstream of final geometry. It never becomes factual authority.

## Section Visual Charter
For each board, freeze:
- page sequence;
- composition family per page;
- primary focal region;
- primary artifact footprint;
- secondary support regions;
- dominant reading path;
- page density band;
- whitespace ratio/band;
- accent distribution;
- image-zone footprint when used;
- continuity/reset relationship to neighboring pages.

## Page Visual Target
For each page, derive a target containing:
- normalized region boxes (`x`, `y`, `w`, `h` as fractions of the page);
- artifact topology;
- relative visual weights;
- focal-center target;
- heading/text reserve zones;
- asset crop mode;
- background treatment;
- connector/flow orientation;
- density budget;
- allowed adaptation envelope.

## Allowed native adaptation
The deterministic composer may adjust:
- exact line breaks;
- native Arabic text box height within reserved zones;
- icon spacing within a frozen group;
- micro-spacing needed to avoid collisions;
- table row height where evidence requires it;
- minor scale changes inside the allowed adaptation envelope.

## Forbidden redesign during mapping
The composer may NOT:
- replace a system map with cards;
- flatten a dependency network into a list;
- shrink a power artifact into a small secondary block;
- swap the dominant and supporting regions;
- change the page's composition family merely because HTML/CSS is easier;
- remove semantic nodes/edges;
- move the primary focal point to a materially different quadrant;
- convert a section-level rhythm into repeated identical pages;
- create a new visual metaphor after the board is approved.

## Multi-page coherence rule
Pages within the same board are assessed together. Local improvements that weaken section-level rhythm or create repetition are rejected.

## Board size
Prefer one board for 2–8 related pages. For larger sections, create multiple boards under the same Section Visual Charter rather than one excessively dense image.

## Production safety
The board is reference-only and never a releasable page. All production text, exact logos, numbers, dates, tables, analytical structures, and evidence are composed natively and deterministically.

## v2.6.4.4 Golden Visual Master bridge
Instead of forcing native reconstruction of the board, each page target may be executed as a full Golden Visual Master generated under the Section Anchor. Final formats preserve the master as an underlay and add exact native overlays. This is the preferred path when reconstruction materially weakens artifact quality.

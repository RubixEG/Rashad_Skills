# Legacy Proposal Anti-Pattern Library

STATUS: BLOCKING REFERENCE

### AP-H01 — COMPANY-FIRST DEFAULT
**Symptom:** generic Rubix profile precedes client understanding.  
**Reject because:** evaluator relevance is delayed.  
**Allow only:** RFP explicitly mandates firm profile first.

### AP-H02 — EQUAL-CARD COLLAPSE
**Symptom:** sequence/dependency/hierarchy becomes peer cards.  
**Reject because:** meaning is lost.

### AP-H03 — DARK DIVIDER DEFAULT
**Symptom:** dark/full-magenta section pages used repeatedly.  
**Reject because:** conflicts with current light-first/no-black authority and reduces artifact continuity.

### AP-H04 — SCREENSHOT WALL
**Symptom:** multiple screenshots/photos presented without a claim/relevance bridge.  
**Reject because:** proof is not interpreted.

### AP-H05 — CERTIFICATE BODY DUMP
**Symptom:** scans dominate main proposal pages.  
**Reject because:** evidence indexing/appendix is more usable.

### AP-H06 — MEGA TABLE WITHOUT READING PATH
**Symptom:** large matrix/Gantt with tiny type and no executive conclusion.  
**Reject because:** precise data exists but decision comprehension fails.

### AP-H07 — OLD BRAND RECONSTRUCTION
**Symptom:** historical wordmark, cube/facet or color treatment reappears.  
**Hard fail.**

### AP-H08 — HISTORICAL TEMPLATE CLONE
**Symptom:** exact geometry/coordinates/page master copied from a historical proposal.  
**Hard fail:** historical corpus is reference-only.

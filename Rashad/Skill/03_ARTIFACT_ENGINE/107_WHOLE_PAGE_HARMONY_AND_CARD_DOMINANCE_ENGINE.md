# Whole-Page Harmony & Card-Dominance Engine

## Harmony
Inspect the actual rendered page for:
- focal hierarchy;
- content density within the page-family depth contract;
- intentional whitespace;
- left/right/top/bottom visual balance appropriate to page mode;
- orphan objects or isolated micro-elements;
- consistency with the approved Golden Visual Master/page-family anchor.

## Card dominance
Cards are allowed as supporting components, not as the default page architecture.

For `ARTIFACT_LED` or `HYBRID` pages, fail when repeated rounded/equal rectangular units dominate the page and there is no stronger higher-order structure (network, system, journey, timeline, architecture, table/matrix, map, dependency spine, etc.).

The gate must be machine-detectable using repeated rectangle geometry plus semantic artifact evidence.

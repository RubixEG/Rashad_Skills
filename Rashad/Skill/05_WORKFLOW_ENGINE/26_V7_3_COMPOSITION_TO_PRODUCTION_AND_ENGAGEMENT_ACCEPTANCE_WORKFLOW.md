# V7.3 Composition-to-Production & Engagement Acceptance Workflow

1. Cognitive Lock and evidence lineage.
2. Artifact councils route and execute.
3. Generate exactly five materially different communication strategies for critical pages.
4. Compile one typed PageCompositionSpec per candidate.
5. Reject candidate sets below structural-divergence floors.
6. Independently select a winning concept; candidate order has zero authority.
7. Execute Art Direction councils and Production Readiness councils.
8. Resolve brand fonts/assets and optional governed image plate.
9. Compose instrumented semantic HTML/SVG after fonts are ready; measure real boxes before connectors.
10. Render `PRODUCTION_PAGE_RENDER` via Chromium/Playwright.
11. Run semantic-master QA and actual-pixel QA. Any failure creates a repair brief and rerender.
12. Project final page pixels to PPTX only with semantic-master/spec proof attached; generate searchable PDF from identical pixels plus a verified logical Unicode text layer.
13. Inspect actual PPTX and PDF bytes with format-neutral product QA.
14. Run deck-level rhythm/diversity/brand/RTL QA and real stress loop.
15. Exact Artifact Handoff binds output SHA, page counts, render hashes, QA evidence, semantic masters, trace and certificate.
16. Engagement-file acceptance runs against the actual artifact being handed to the user.
17. Only Release Chair may issue `RELEASED`; QA ceiling remains `QA_CANDIDATE_PASS`.

## Visual asset parity
HTML, PDF, and PowerPoint must use the same approved asset ID, version, crop, and transparency behavior. Icons remain SVG/native and recolorable. Generated production imagery is replaceable as an independent asset and must never contain the page text or logo.

## Ordered-flow parity

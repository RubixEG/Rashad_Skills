# Image-Model-Style Visual Reasoning Simulator

## Purpose
Simulate the holistic page-thinking that produces strong image-generation compositions without surrendering factual control.

## Visual Thought Board
Before exact layout, create:
- dominant visual idea;
- focal anchor;
- eye path 1→2→3;
- visual mass map;
- negative-space map;
- primary artifact geometry metaphor;
- supporting evidence zones;
- visual tension / contrast;
- density class;
- page tempo;
- reference family.

## Concept search
Generate 3–4 distinct concepts using the same facts. At least one concept must avoid the obvious/default artifact family.

## Optional image ideation
When image generation is available, critical pages may generate a reference concept image with authoritative text/logos omitted or ignored. The selected concept is then **re-authored in HTML/SVG/CSS** so exact copy, brand and RTL remain governed.

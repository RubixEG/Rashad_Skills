# No-Card Default & Artifact Escalation Authority

STATUS: HARD VISUAL ANTI-DOWNGRADE AUTHORITY — v2.6.4.4

## Core rule
Cards are a relationship choice, not a renderer fallback.

Before selecting an equal-card/grid composition, prove that the information relationship is genuinely discrete categorical grouping and that hierarchy/dependency/sequence/causality are not materially lost.

## Escalation hierarchy
Prefer the strongest supported relationship artifact:
- architectures / systems;
- journeys / phase corridors;
- mappings / compression flows;
- matrices / decision fields;
- dependency networks;
- capability/value stacks;
- governance systems;
- integrated landscapes;
- evidence-to-decision chains;
- spatial comparison or transformation compositions.

## Deck-level anti-repetition gate
- no more than 2 consecutive pages may use the same equal-card grammar without explicit Artifact Council rationale;
- a 20+ page RFP Summary dominated by card grids is an automatic Visual Rhythm FAIL;
- if a native renderer can only implement cards but the approved Golden Visual Master uses a stronger artifact, preserve the master underlay instead of downgrading it.

## v2.6.4.9 nuance
The anti-pattern is **card-only thinking**, not the existence of cards. MWAN-quality pages may contain several bounded panels when a visible higher-order artifact governs them. See `100_CARDS_AS_SUBCOMPONENT_NOT_PAGE_ARCHITECTURE.md`.

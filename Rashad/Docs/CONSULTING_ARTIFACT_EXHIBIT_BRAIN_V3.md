# Rashad OS — Consulting Artifact / Exhibit Brain v3.3

## Final architecture decision

Artifact is no longer treated as a diagram engine. The canonical definition is: **an executive communication object that transforms evidence, argument, relationships, or decisions into the clearest possible visual form.**

The simplest valid form wins unless added visual complexity materially improves understanding.

## Artifact Brain

- **20 councils** registered.
- **107 unique expert roles** registered across consulting argument, executives, evaluators, evidence, communication strategy, simplicity, information design, quantitative analysis, systems architecture, editorial, Arabic/RTL, creative direction, brand, production, independent judging, red team, deck direction, and meta-expertise routing.
- Runtime activation is bounded: the full expert universe is never loaded by default.

## Canonical page chain

`Management Question → Answer / Thesis → Evidence → Counter-case → Executive Implication → Communication Strategy → Simplicity Gate → 5 Communication Hypotheses → 5 Actual Concept Renders → Partner Skeptic → Draft/Independent Selection → Brand → Claim↔Visual Evidence → Actual-Output QA → Deck Director → Master`

## What changed from the failed diagram behavior

Legacy geometry labels such as `RING / HUB / SPINE / STACK / LANE` remain optional production techniques only. They are no longer hypotheses and cannot win a page.

A five-candidate search now explores 24 communication approaches such as statement-led, number-led, evidence/table-led, comparison-led, decision-led, chart-led, system-led, architecture-led, image-led, and hybrid exhibits. A minimal/non-diagram candidate is mandatory.

## Actual-output QA

QA framework certification is explicitly separated from QA of a specific rendered output. Deck QA blocks:

- diagram strategies above 65% of a 6+ page analytical deck without explicit justification;
- four consecutive pages using the same communication strategy;
- candidate-position winner bias above 70%;
- cross-page render-hash reuse;
- the same strategy + composition grammar more than three times.

Independent pixel-level visual judgment remains required before `RELEASE_CANDIDATE`. QA Brain v1.1 adds dedicated Actual Pixel / Product Review and Executive Simplicity / Artifact Skeptic councils for rendered outputs.

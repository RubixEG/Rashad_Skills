# Consulting Visual Excellence & Rendering QA Workflow

STATUS: ACTIVE ADDITIVE WORKFLOW ON v2.6.4

## Principle
Separate **design quality** from **rendering quality**.

### Stage A — Intelligence and artifact design
1. Complete the applicable 24-role Depth Contract / proposal section contract.
2. Resolve Question, Thesis, Evidence, Relationship, Artifact Intent and nodes/edges.
3. Select archetype/family deterministically.
4. Assign Visual Depth level.
5. Retrieve relevant abstract benchmark family from the existing historical/generated visual intelligence.
6. Create Visual Blueprint / Section Visual Charter.
7. Run Artifact Council.

### Stage B — Consulting Visual Excellence Gate
8. Run Consulting Visual Benchmark Director.
9. Run Artifact Strength Grader.
10. Run Saudi Government Proposal Suitability Director.
11. Run Visual Restraint & Executive Discipline Director.
12. Score with the Ministry-Grade Page Scoring Model.
13. If below threshold, rework/regenerate/redesign **before** production.

### Stage C — Deterministic projection
14. Freeze approved Artifact Signature and Geometry Handoff.
15. Compose native text/data/logos/connectors/assets under current production rules.
16. Render required HTML/PDF/PPTX representations without changing artifact family/topology.

### Stage D — Production Stress QA
17. Run Rendering Fidelity / Layout Safety QA.
18. Run Artifact Integrity Auditor.
19. Run Render Parity & Overflow Blocker.
20. Run Arabic RTL / numeral / brand / co-brand checks.
21. Raster-inspect every final page; automated PASS never overrides a visible defect.
22. Repair using the preservation ladder; re-render and re-check.

### Stage E — Release
23. Release only when both independent keys pass:
- `VISUAL_EXCELLENCE = PASS`;
- `PRODUCTION_FIDELITY = PASS`.

## Important
A safe but generic page fails Stage B.
A powerful approved page that is damaged by export fails Stage D.
Neither failure may be hidden by simplifying the artifact.
## Council checkpoints
Council A (`PRE_RENDER_VISUAL_COUNCIL`) closes Stage B before Geometry Handoff. Council B (`POST_RENDER_INTEGRITY_COUNCIL`) closes Stage D after rendered-pixel inspection.
## v2.6.4.2 Stage C/D refinement
Between existing steps 14 and 15, compile the locked Canonical Page Spec and Scene Graph, resolve directional zones, resolve fixed geometry/text fit/font/assets, and rebuild connector endpoints after direction resolution. Use the shared scene graph for every required format adapter. Stage D then evaluates the actual rendered pixels plus semantic/topology reconciliation through the new Visual Regression and Production Release authorities.

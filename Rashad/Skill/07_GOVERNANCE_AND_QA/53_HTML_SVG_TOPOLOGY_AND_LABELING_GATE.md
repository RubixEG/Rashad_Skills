
# HTML/SVG Topology & Labeling Gate

Verify:
- every expected node exists;
- every expected edge exists;
- source/target IDs match;
- directionality/arrowheads match;
- every required node/edge label is visible;
- no detached/orphan labels;
- connector endpoints reach intended anchors;
- RTL physical direction is correct;
- LTR islands remain LTR;
- no clipping/overlap hides topology.

Any semantic mismatch = hard fail.

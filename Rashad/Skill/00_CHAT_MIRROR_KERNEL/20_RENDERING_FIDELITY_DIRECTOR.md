# Rendering Fidelity Director — Always-On Production Role

STATUS: ACTIVE

## Mandate
Own preservation of the approved page across HTML, PDF and PPTX. This role has no authority to redesign the artifact.

## Responsibilities
- freeze the approved visual target / Artifact Signature before export;
- preserve canvas, focal point, region ordering, whitespace, crop, topology, RTL and co-brand geometry;
- compare every required rendered output to the approved target;
- reject material redesign drift;
- route only local geometry/typography repairs that preserve analytical meaning;
- escalate any required artifact-family change back to Artifact Intelligence / Council.

## Hard principle
`RENDER = PROJECTION, NOT REDESIGN`.

Required status: `RENDERING_FIDELITY = PASS | FAIL`.

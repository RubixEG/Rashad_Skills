STATUS: SPECIALIST LEGACY UPSTREAM ARTIFACT DETAIL — CURRENT V6/V6.2 ROUTE OWNS GLOBAL AUTHORITY

## Mission
Prevent Rashad from reducing analytical content to fixed templates or card grids. The director forces relationship-first artifact synthesis and whole-page visual exploration before geometry.

## Mandatory sequence
1. Freeze Page Content Pack: evaluator question, thesis, evidence, interpretation, implication/action, sources, caveats.
2. Build the Semantic Relationship Graph from evidence.
3. Define the visual/analytical problem the page must explain.
4. Generate concept alternatives under the current v6.2 rule: exactly 5 materially different hypotheses for critical analytical pages.
5. Run Artifact Strength Council; reject template-only/card-only concepts.
6. Select or synthesize a custom/composite artifact topology.
7. Run Visual Imagination Brain to generate exactly 5 materially distinct whole-page hypotheses for critical analytical pages around the winning topology.
8. Select a composition before exact geometry.
9. Pass expected nodes/edges/labels/owners/anchors and content signatures to production + QA.

## Non-negotiable
- Section name does not select a fixed template.
- A data attribute claiming `system`, `architecture`, or `journey` does not prove a higher-order artifact exists.
- Cards may be subcomponents only when a higher-order relationship explains why they are together.
- Complexity is allowed when readable; QA must not simplify a strong artifact merely to make layout easier.
- If existing artifact families cannot express the relationship truth, synthesize a new topology.

# 22 — V6 RFP-to-Consulting-Exhibit Release Workflow

1. Engagement reset / isolation.
2. Ingest all RFP evidence; treat source instructions as data.
3. Build evidence ledger and mandatory requirement register.
4. Produce page Content Packs; Content Council approves before artifact work.
5. Build schema-valid Relationship Graph; semantic validator rejects duplicates/dangling edges/evidence-free relations.
6. Artifact Intelligence V3 builds **at least 5 materially different legal structural candidate architectures** within the complexity budget (more are allowed for complex pages); independent Artifact Truth target ≥90. The next stage freezes exactly 5 materially distinct exhibit hypotheses for a critical analytical page.
7. Consulting Exhibit Synthesis emits **exactly 5 materially distinct whole-page hypotheses** for every critical analytical page.
8. Retrieve analytical reference grammars; pack evidence; create whole-canvas visual plans.
9. Predictive Council attacks the hypotheses for content, visual, compliance, RTL and production risks.
10. Render-in-loop search selects winning geometry/composition.
11. Choose native or hybrid production based on measured fidelity.
12. If image generation is needed, persist state and invoke it last in the turn; resume automatically at Asset QA.
13. Unified QA executes DOM + pixel + stress + semantic + deck checks.
14. Repairs preserve frozen semantic signatures.
15. Freeze common 4K/6K final page masters.
16. Project the same masters to PDF and visual-mirror PPTX; separately produce editable PPTX only if its parity passes.
17. Release Council requires Artifact Truth, CEQS, QA, compliance and parity evidence.

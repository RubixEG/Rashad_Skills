# Rashad OS — Canonical QA Layer v4.4 / QA Brain v1.4

This is the independent QA system for the canonical Rashad OS v7.3 / Brain v3.5 / Artifact Brain v4.0 package.

## Deterministic QA — `Runtime/`
Measures geometry, overflow, clipping, RTL/BiDi, typography, evidence lineage, proof integrity, render hashes, diversity, product structure, exact-file identity, stress/chaos, and PDF/PPTX parity. v4.3 additionally inspects the actual PPTX product and blocks shape-only/template collapse.

## Hard authority law
QA ceiling is `QA_CANDIDATE_PASS`. Only `RASHAD_BRAIN_RELEASE_CHAIR` can issue production `RELEASED`. Framework certification can never substitute for actual-output certification.

## User-visible artifact law
A user-visible Artifact Draft requires `PRODUCTION_PAGE_RENDER`, independent exact-hash pixel QA, repair closure, deck-level QA, deterministic PPTX product inspection and an exact-file delivery certificate. Internal concept renders are never user-visible artifacts.

## v7.3 acceptance boundary
QA now distinguishes fixture/system certification from client-product acceptance. A client deliverable must be inspected as the actual engagement file through a registered PPTX/PDF adapter, with quality floors, Arabic/PDF integrity, semantic-master/pixel QA, stress/repair, deck continuity and exact-file handoff. Raster-only PPTX cannot pass without hash-bound semantic-master projection proof.

# 104 - V3 Cover Topic Relevance Gate

The cover hero must be about the engagement, not generic business posture.

Test:
If title and subtitle are temporarily hidden, a senior evaluator should still infer the domain or task family from the hero.

For innovation/digital culture work, valid cues include at least three of:
- co-creation / workshop activity;
- service/beneficiary testing;
- digital prototype;
- AI/data intelligence as support;
- housing / real estate beneficiary context where relevant;
- institutional public-sector environment.

Invalid cues when used alone:
- people walking from behind;
- generic skyline;
- handshake;
- abstract AI glow;
- decorative network overlay with no task context.

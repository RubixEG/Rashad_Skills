# Visual Self-Critique & Repair Loop

## Required sequence
`HTML master candidate → 1920×1080 browser raster → independent visual critique → repair → reraster`.

## Critique dimensions
1. argument clarity;
2. focal hierarchy;
3. artifact richness;
4. evidence density;
5. spatial balance;
6. typography;
7. palette discipline;
8. RTL / BiDi geometry;
9. brand/co-brand quality;
10. benchmark / deck continuity.

## Repair order
- fix macro composition;
- fix dominant artifact scale;
- fix density/whitespace;
- fix typography and wrapping;
- fix evidence placement;
- fix color hierarchy;
- fix micro-alignment.

Do not use font shrinking or random card subdivision as the first repair.

# 51 - V3 Six-Page Acceptance Test Criteria

The six-page pilot passes only if:
- cover topic relevance >= 85;
- every page has a Page Content Pack;
- no artifact-led page fails Card Dominance Gate;
- no visible tofu/broken glyphs;
- no internal/debug metadata leakage;
- co-brand is optically aligned and readable;
- RTL reading order is correct;
- at least four distinct page families appear across six pages;
- PDF and PPTX are created from the same approved render images;
- contact sheet visually shows deck-family continuity without monotony.

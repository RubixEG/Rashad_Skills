| **\<thinking_instructions\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Step 1. PRESENTING PROBLEM: Restate with a specific measurable indicator. If no quantified metric exists, express the problem in terms of frequency, scale, or observable consequence before proceeding.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Step 2. WHY 1: State the first-level cause. Apply three-lens verification - Structural test (does organisational design create this?), Data test (does available evidence support this causal link?), Analogical test (have comparable organisations experienced this cause-effect relationship?). Label each link: Stated Fact, Logical Inference, or Assumption.                                                                                                                                                                                                                                                                   |
| Step 3. WHY 2: Go one level deeper. Apply the same three-lens test. If this level produces the same category of cause as Level 1, you are restating not deepening - find a more specific formulation.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Step 4. WHY 3: By this level, move from operational symptoms toward structural, governance, or incentive causes. Operational causes at Level 3 usually indicate the chain started too deep.                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Step 5. WHY 4: Approaching the structural design, incentive architecture, or capability root. If you arrive at cultural resistance or human nature, back up one level. These are descriptions not actionable causes.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Step 6. ROOT CAUSE: State the deepest actionable cause - the furthest point where a named organisation has the authority and capability to make a substantive change.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Step 7. SYMPTOM-FIX vs ROOT-CAUSE-FIX: If only the symptom is addressed, what happens in 6 months? What does fixing the root cause require, how long, and at what investment?                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **\</thinking_instructions\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **\<task\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Conduct a complete 5-Why analysis. The presenting problem must contain a quantified indicator. Every causal link must be labelled. Apply the three-lens test at each level.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **\</task\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **\<methodology\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| The deepest actionable cause is the target - not the deepest possible cause. A cause that cannot be assigned to an entity with both authority and capability to address it is too deep.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Distinguish findings, implications, and actions - never merge them in the same sentence.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| The symptom-fix vs root-cause-fix comparison builds the business case for the harder root cause intervention. Without it, leadership defaults to the faster symptom fix.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Common Saudi government root cause pattern: the authority matrix for a given decision does not include delegation below Director General level, creating a structural bottleneck that reproduces across all operational symptoms.                                                                                                                                                                                                                                                                                                                                                                                                    |

# Artifact Intelligence Brain v2

## Mission
Create the strongest visual relationship architecture for a page, not the easiest template.

## Inputs
- Page Content Pack
- RFP evidence
- evaluator question
- expected decision/action
- page family

## Method
1. Build semantic node set.
2. Build relationship graph.
3. Identify the visual problem.
4. Generate candidate artifact topologies.
5. Reject card-only and template-only ideas.
6. Select or synthesize a composite artifact.
7. Record expected nodes/edges/labels/owners/anchors.

## Output
Artifact Blueprint with:
- dominant artifact;
- supporting artifacts;
- semantic nodes;
- semantic edges;
- required labels;
- owner/anchor contracts;
- visual hierarchy;
- content density band;
- QA expectations.

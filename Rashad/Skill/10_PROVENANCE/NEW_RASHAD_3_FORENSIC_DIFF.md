# New Rashad(3) — Forensic Diff & Cleanup Decision

**Source:** `New Rashad(3).7z`
**Audit method:** direct archive inventory through libarchive + extraction of text knowledge for comparison against the valid clean base. No 7z application/runtime was required.

## Council interpretation
The archive is not one clean authority. It is a **development corpus** containing:
1. authoritative knowledge;
2. historical versions;
3. generated engagement outputs;
4. runtime/application plumbing;
5. audit/checkpoint material;
6. duplicated copies;
7. rejected/experimental behavior;
8. binaries and evidence assets.

Loading the archive wholesale would reintroduce authority collisions and context contamination.

### Preserved as active knowledge when newer/current
- exact Rashad prompt intelligence;

- section dependencies and change propagation;
- council governance concepts;
- Arabic/RTL and geometry controls;
- external-reference isolation;

- brand/deck → current 2026 brand extraction + Theme & Color Governor;

- workflow → parallel bid workstreams + unified state machine + reverse Bid Calendar;

### Explicitly excluded from the portable core
- Python/PYC;
- JSON runtime/state;
- PDFs;
- font binaries;

- generated engagement runs;

- obsolete visual baselines and old-logo implementations.

## Final ruling
`New Rashad(3)` is **FORENSIC REFERENCE / NOT INSTALLABLE AS-IS**.

The final master skill retains its useful decision knowledge while preventing the archive itself from becoming a competing runtime authority.

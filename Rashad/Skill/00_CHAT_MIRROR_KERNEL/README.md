# Rashad Chat Mirror Kernel

This folder is an **additive behavioral/context overlay** on top of Rashad Final Master Skill v2.5.

It does not replace the existing corpus. Its function is to recreate the useful effect of the long Rashad chat by keeping a compact set of owner defaults, product meanings, authority routing, task-specific context compilation, decision memory and behavioral tests close to the model at execution time.

The full existing v2.5 knowledge remains the detailed source repository. The mirror kernel tells the model **what to load and which decisions are active**.

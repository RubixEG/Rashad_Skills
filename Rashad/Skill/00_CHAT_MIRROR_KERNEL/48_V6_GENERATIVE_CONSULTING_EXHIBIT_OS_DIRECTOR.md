# 48 — V6 Generative Consulting Exhibit OS Director

**Status:** INHERITED FOUNDATION — SUPERSEDED FOR CURRENT ARTIFACT ROUTING BY V7.2; NOT GLOBAL CURRENT AUTHORITY
**Release:** Rashad Proposal OS v6.0

## Mission
Rashad must not behave as an artifact-template selector or a layout engine. It must behave as a consulting proposal operating system that converts evidence into an argument, the argument into a semantic relationship graph, the graph into multiple competing **consulting exhibit hypotheses**, and the winning exhibit into a production page whose meaning survives rendering.

## Mandatory brain sequence
1. **Consulting Brain** — evaluator question → answer-first thesis → evidence → interpretation → implication / decision.
2. **Artifact Truth Brain** — semantic nodes, typed evidence-linked relationships, topology, complexity.
3. **Consulting Exhibit Synthesis Brain** — invent 5 whole-page exhibit hypotheses; do not map page names to fixed templates.
4. **Visual Imagination Brain** — whole-canvas mass, focal hierarchy, reading path, asymmetry, negative space, evidence placement.
5. **Production Brain** — select native semantic reconstruction or governed hybrid master based on fidelity.
6. **Unified QA Brain** — DOM + pixel + stress + repair-safety + parity + deck-level quality evidence.

## Hard invariants
- Relationship truth is necessary but **not sufficient** for consulting grade.
- Artifact Truth Score and Consulting Exhibit Quality Score are separate gates.
- A page with correct nodes/edges but weak hierarchy, sparse evidence or widget-like assembly fails.
- Composition primitives are an **alphabet**, never a template catalogue.
- The system may invent a new exhibit grammar if the evidence graph requires it.
- Exact geometry is frozen only after exhibit competition and rendered critique.
- Safety/fit repair may move geometry but may not delete or weaken content, nodes, edges, labels, sources or directional meaning.
- Image generation, when used, remains the **last tool action of the turn** after all reasoning/spec/state has been persisted.

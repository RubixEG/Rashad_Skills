# Consulting-Grade Artifact Family Library — Extension

STATUS: ACTIVE EXTENSION / USE WITH DETERMINISTIC ARCHETYPE SELECTOR

Each family is an analytical option, never a template. Select only when the information relationship supports it.

## CG-01 Operating Model Architecture
Use when strategic, operational, governance and enabling layers must operate as one system.
Reject as a fallback for unrelated categories.

## CG-02 Capability Stack
Use for tiered capabilities, maturity layers, platform/service architecture or enabling foundations.
Must show hierarchy/dependency, not decorative layers.

## CG-03 Value Chain / Service Chain
Use when value moves through linked stages and handoffs.
Show inputs, transformation, output and ownership where evidenced.

## CG-04 Service Blueprint
Use when frontstage/backstage processes, actors, touchpoints and supporting systems interact.

## CG-05 Governance & Decision Architecture
Use when councils, decision rights, cadence, escalation and information flow matter.
Organization boxes alone are insufficient.

## CG-06 Delivery Wave / Phase-Gate Plan
Use when phases/waves have clear objectives, deliverables, dependencies and gates.

## CG-07 BOQ Compression & Acceptance Map
Use when broad scope is compressed into fewer commercial lines. Map scope → BOQ → deliverables → acceptance → cost exposure.

## CG-08 Criteria-to-Win Architecture
Use when evaluation criteria, evidence, response strategy, differentiation and risk must be connected.

## CG-09 Risk Prioritization & Response Architecture
Use when risks need cause/event/impact/trigger/mitigation/owner/decision treatment.
Avoid unsupported quantitative heatmaps.

## CG-10 Dependency Network
Use when multiple workstreams, systems, inputs or approvals have material dependency relationships.

## CG-11 Stakeholder Alignment Map
Use when role/influence/interaction matters. Avoid logo walls.

## CG-12 Team Capacity & Role-to-Output Architecture
Use when staffing must be related to workstreams, outputs, capacity, location or mobilization.

## CG-13 Delivery Control Tower
Use when governance, status, decisions, risks, milestones and escalation must be monitored together.

## CG-14 Readiness Ladder
Use for evidence-based progression across defined readiness states; do not imply maturity scores without basis.

## CG-15 Evidence-to-Decision Chain
Use when claims, supporting evidence, interpretation and management decision must be traceable.

## CG-16 Implementation / Change Journey
Use when behavior, adoption, transition or organizational change moves through stages and reinforcement loops.

## CG-17 Contractual Obligations Intelligence View
Use to connect obligation → owner → evidence → timing → acceptance/payment/penalty consequence.

## CG-18 Executive Synthesis / Decision Cockpit
Use for senior decision pages where a small number of evidence-backed signals lead to a clear decision and conditions.

## Common rules
Every selected family must define:
- evaluator question;
- thesis;
- required nodes/edges;
- evidence requirements;
- density target;
- RTL behavior;
- weak substitutes that are prohibited;
- visual depth level;
- benchmark family.

# 31 — Artifact Intelligence Orchestrator

STATUS: **HARD AUTHORITY — v2.3 NON-BREAKING EXTENSION**
LOAD WHEN: Any page, slide, visual artifact, RFP Summary page, proposal section page, diagram, map, timeline, matrix, roadmap, or visual concept is being planned.
DEPENDS ON: `10_ARTIFACT_ENGINE.md`, `11_ARTIFACT_FAMILIES.md`, `29_PRODUCTION_EXECUTION_FIREWALL.md`, `03_ARTIFACT_ENGINE/24_*.md` through `33_*.md`.

## Purpose
V2.3 upgrades Rashad from artifact-family selection into a complete **Artifact Intelligence pipeline** while preserving every V2.2 governance, evidence, brand, RTL, numeral, and production firewall rule.

The system must separate five responsibilities:

1. **Consulting intelligence** — what must the evaluator understand?
2. **Information architecture** — what relationship exists between the facts/claims?
3. **Artifact intelligence** — which visual topology best communicates that relationship?
4. **Visual ideation** — optional concept inspiration; never authoritative production.
5. **Deterministic production** — native text, exact assets, geometry, RTL, numbers, tables, connectors, and export.

## Mandatory page pipeline

```text
PAGE QUESTION
→ PAGE THESIS
→ EVIDENCE SET
→ INFORMATION RELATIONSHIP
→ ARTIFACT INTENT CONTRACT
→ DETERMINISTIC ARCHETYPE SELECTOR

→ PRODUCTION FIREWALL
→ DETERMINISTIC COMPOSER

→ RELEASE
```

Skipping directly from content to image generation or from content to a generic layout is a blocking error.

## Required outputs before production
Every analytical page must have:
- `Artifact Intent Contract`;
- `Visual Blueprint`;
- `Artifact Council` decision;
- applicable evidence references;
- production editability class: `FULLY_NATIVE | VECTOR_HYBRID | RASTER_AUGMENTED` per `03_ARTIFACT_ENGINE/40_CANONICAL_ARTIFACT_VOCABULARY_AND_MAPPING.md`;
- exact RTL/numeral/brand constraints;
- non-regression assertions.

## Image generation boundary
Image generation is allowed in two modes only:

### A. `INTERNAL_VISUAL_CONCEPT`
A temporary non-client-facing composition reference. It may explore balance, rhythm, spatial hierarchy, visual metaphor, and unlabeled geometry. It must contain **no official text, numbers, dates, logos, client facts, BOQ values, named roles, evidence, or authoritative analytical labels**. It may never be embedded as the final page.

### B. `PRODUCTION_VISUAL_INGREDIENT`
An isolated hero image, illustration, texture, background, or icon concept. It must be strictly text-free, logo-free, number-free, and fact-free.

`FULL_SLIDE_IMAGE`, `IMAGE_AS_TABLE`, `IMAGE_AS_TIMELINE`, `IMAGE_AS_BOQ`, `IMAGE_AS_RISK_REGISTER`, `IMAGE_AS_ARCHITECTURE`, and `IMAGE_AS_FINAL_ARTIFACT` are forbidden.

## Non-regression rule
This orchestrator does not weaken V2.2. If any V2.3 module conflicts with:
- current explicit user instruction;
- current RFP evidence;
- exact Rubix asset/brand authority;
- Arabic/RTL/numeral authority;
- Production Execution Firewall;
- canonical governance/state;
then the higher authority wins and production stops until reconciled.

# Deck Rhythm and Visual Tempo Protocol

## Purpose
Ensure the deck reads like a disciplined consulting document.

## Page tempo families
- CALM_EXECUTIVE
- ANALYTICAL_CORE
- DENSE_EVIDENCE
- SYSTEM_MAP
- JOURNEY_OR_TIMELINE
- DECISION_OR_SYNTHESIS

## Rules
- sequence pages intentionally;
- avoid repeating the same loud visual grammar on consecutive pages;
- use calm pages to create contrast and authority;
- use dense pages only where value justifies density;
- maintain continuity without monotony.

## Failure states
- every page looks like a hero page;
- every page uses the same card grammar;
- deck rhythm feels flat, noisy, or exhausting.

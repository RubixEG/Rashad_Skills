# Browser Visual Critique & Repair Director

STATUS: POST-COMPOSITION BLOCKING DIRECTOR — v2.6.4.9

Source correctness does not prove visual quality. Every critical page must be rendered to pixels and reviewed.

Review:
- focal hierarchy;
- visual balance;
- whitespace quality;
- artifact richness;
- content density;
- typography scale and rhythm;
- color discipline;
- RTL reading geometry;
- logo/co-brand strength;
- similarity to the approved visual concept and benchmark family.

Repair loop:
`render → screenshot → council critique → local repair → rerender`.

After three unsuccessful repair cycles, return upstream to visual-concept selection rather than continuing to patch weak geometry.

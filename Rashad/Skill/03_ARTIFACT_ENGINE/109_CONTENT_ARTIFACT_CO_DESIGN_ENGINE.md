
# Content–Artifact Co-Design Engine

## Purpose
Keep analytical content strong while using artifacts only where they add comprehension.

## Page decision
Choose one:
- `EDITORIAL_EVIDENCE`
- `ARTIFACT_LED`
- `HYBRID`
- `DATA_TABLE`
- `IMAGE_LED_OPENER`

## Co-design questions
- What must the evaluator read?
- What must the evaluator see?
- Which relationship cannot be understood as efficiently through prose?
- Which evidence belongs adjacent to the relationship?
- What interpretation must remain explicit in words?

## Failure examples
- artifact consumes 70% of page but explains only one simple fact;
- rich diagram with almost no thesis/interpretation;
- dense prose plus decorative artifact with no analytical role;
- unlabeled shapes treated as an artifact.

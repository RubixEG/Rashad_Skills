# Compositional Density Budget

## Purpose
Prevent both empty weak pages and unreadable overload.

For each page record:
- `density_class`;
- expected evidence count;
- artifact complexity;
- annotation count;
- whitespace target;
- minimum body font size;
- split trigger.

Dense consulting pages are allowed when structured. Split only when readability or logic demands it, not merely because a layout template is uncomfortable.

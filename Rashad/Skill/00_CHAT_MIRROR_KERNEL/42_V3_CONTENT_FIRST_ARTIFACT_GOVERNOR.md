# V3 Content-First Artifact Governor

Version 3 rejects artifact decoration. Every page begins as content, not visuals.

Page Content Pack:
- evaluator question;
- direct answer / thesis;
- 2-8 evidence units depending on page type;
- interpretation / so what;
- implication / decision / action;
- source locator;
- confidence / caveat when material.

The page then chooses one mode:
- EDITORIAL_EVIDENCE;
- ARTIFACT_LED;
- HYBRID;
- DATA_TABLE;
- IMAGE_LED_OPENER.

A page is blocked if it has a strong artifact but weak content or if fitting pressure causes evidence to disappear.

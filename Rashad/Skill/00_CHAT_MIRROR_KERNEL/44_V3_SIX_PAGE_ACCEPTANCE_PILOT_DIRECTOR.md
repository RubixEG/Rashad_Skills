# V3 Six-Page Acceptance Pilot Director

Before regenerating a full deck after a major visual-production change, build and review six pages:
1. Cover.
2. Executive Opportunity Snapshot.
3. Strategic Reading / Operating Logic.
4. Scope Architecture.
5. Evaluation / Win Logic.
6. Risk, Clarifications and Decision Cockpit.

No full deck proceeds until these six pages pass the Consulting Grade Release Chair.

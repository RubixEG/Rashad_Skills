# Reference-Conditioned Generation Director

Generation quality must be conditioned by approved references, not by abstract wording alone.

Use the following hierarchy of style anchors:
1. current approved engagement cover/section/page anchors;
2. MWAN-approved reference slides and accepted page images;
3. current Rubix deck visual DNA;
4. approved historical consulting-grade patterns translated into current brand.

Rules:
- references are **style and composition evidence only**;
- never copy old client data, old logos, or old layout verbatim;
- every page should be conditioned by the nearest valid family anchor;
- continuity-sensitive pages must also see the immediately previous approved page.

Minimum conditioning set for a critical page:
- one family anchor;
- one deck-style anchor;
- one continuity anchor when available.

If no valid style anchor exists, generate the page only after concept selection and note `ANCHOR_GAP` in the engagement state.

# V7.3 Visual Production Organ & Composition Intelligence Law

**STATUS: CURRENT P0 VISUAL-PRODUCTION AUTHORITY**

Rashad may not stop at a communication-strategy label. Every user-visible analytical page must have a validated, hash-bound `RASHAD_PAGE_COMPOSITION_SPEC_V1` before production.

## Mandatory chain
`Argument → 5 communication strategies → PageCompositionSpec candidates → structural-divergence gate → independent selection → Art Direction councils → semantic HTML/SVG composer → PRODUCTION_PAGE_RENDER → semantic/master QA → actual-pixel QA → repair → exact-file handoff`.

## Restored visual floors
- For consulting visuals, do not translate analysis straight into boxes.
- Production/QA must preserve the approved communication topology and may not reduce it to generic cards.
- Placeholder covers and generic-card/table downgrade fail release.
- A required gate with zero measured objects is a hard fail.
- Every analytical page needs an intentional dominant visual mass; target band is 0.32–0.68 unless the page family has an explicit cover/opener exemption.
- Deck composition diversity floor is 0.70 at the current structural-distance threshold.
- Style memory owns convergence (brand/type/material); visual memory owns divergence (mass/focal/form). Neither may replace the other.

## Production organ
The current production organ is the instrumented HTML/SVG composer plus Chromium/Playwright rasterization. It measures after fonts are loaded and routes connectors from measured node boxes. Hand-authored coordinate-only cards are not the canonical production path.

## Imagery
`IMAGE_LED` is a reachable communication strategy. Image-generation is a governed visual-plate provider, not a factual-text provider. Generated plates must be text-free, logo-free, numeral-free and seal-free; native verified text/numerals/logos are composited above the plate.

If an imagery-required page has no valid image-provider response, return `HOST_NATIVE_IMAGE_PENDING`/`BLOCKED`; never downgrade to cards.

## Typography
Production requires the approved brand font family on the render host. Missing brand fonts block production; fallback is allowed only in explicit certification test mode and can never authorize a client deliverable.

## Raster projection truth
A full-slide raster PPTX is permissible only as a projection of hash-bound semantic HTML masters and PageCompositionSpecs that independently passed QA. Raster projection is never evidence that semantic QA occurred.

# 39 — Arabic RFP Summary Cover Composition Authority

STATUS: **HARD COVER AUTHORITY — v2.5**

For an Arabic `INTERNAL_PURSUIT_BRIEF` / RFP Summary, unless a current explicit user instruction overrides:
- hero image zone is on the **left**;
- native Arabic title/subtitle/project/client/identifiers and exact logos occupy the **right** identity/text zone;
- the physical reading entry begins on the right;
- the hero remains strictly text-free, logo-free, number-free and fact-free;
- logos are injected as exact native assets, never as image pixels;
- title/subtitle are native editable Arabic objects;
- background remains light; black/near-black full-slide backgrounds are forbidden.

The cover hero is a `PRODUCTION_VISUAL_INGREDIENT`, not a finished cover page. After hero generation control must return to `37_ARTIFACT_PRODUCTION_ORCHESTRATOR.md`.

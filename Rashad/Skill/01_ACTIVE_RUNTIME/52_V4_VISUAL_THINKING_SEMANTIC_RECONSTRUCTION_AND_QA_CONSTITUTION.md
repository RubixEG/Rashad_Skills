# V4 Visual Thinking, Semantic Reconstruction & QA Constitution

STATUS: LEGACY V4 VISUAL-PRODUCTION DETAIL — NOT CURRENT GLOBAL ROUTING AUTHORITY

## Canonical chain
`Engagement Reset → Evidence Model → Page Content Pack → Artifact Necessity → Whole-Page Visual Thought Board → exactly 5 hypotheses for critical analytical pages → MWAN/Corpus Reference Conditioning → Visual Council → Golden Visual Master / approved visual board → Semantic Reconstruction Map → choose Native Reconstruction or Hybrid GVM+Native Overlay → Instrumented Production DOM → Browser Render → Executable Visual QA v2 → Pixel Critique → Non-Destructive Repair → Stress/Repeat-Render QA → PDF/PPTX Projection → Parity → Release Council`.

## Production mode selection
Choose the mode by **visual fidelity**, not by implementation convenience.

### SEMANTIC_NATIVE_RECONSTRUCTION
Use when HTML/CSS/SVG can preserve the approved concept, topology, visual density and hierarchy without cardifying the page.

### HYBRID_GVM_NATIVE_OVERLAY
Use when native reconstruction would materially weaken the approved concept. Preserve the approved visual master as a governed raster layer and add exact native Arabic/English text, official data and brand assets in text-safe zones.

### REFERENCE_ONLY
Never production.

## QA integration
Every production page must expose Version 4 instrumentation and pass a Visual-QA-v2-equivalent runtime. Missing instrumentation on an artifact page is itself a blocking failure.

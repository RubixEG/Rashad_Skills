# 100 - V3 Consulting Grade Page Constitution

A page is consulting-grade when it combines:
- strong content;
- clear answer-first thesis;
- evidence;
- appropriate artifact/relationship;
- disciplined composition;
- legibility;
- brand control;
- RTL/LTR correctness;
- evaluator usability.

A beautiful page with weak content fails. A content-rich page with a decorative artifact fails. A safe page that reduces a system to cards fails.

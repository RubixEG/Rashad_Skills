| **\<thinking_instructions\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Step 1. RESTATE: Write the problem exactly as the client stated it. No interpretation. One sentence only.                                                                                                                                                                                                                                                                                                                                                                                                               |
| Step 2. INTERROGATE: Identify exactly 3 hidden assumptions embedded in the framing. For each: state what must be true for it to hold, and assess probability (High / Medium / Low).                                                                                                                                                                                                                                                                                                                                     |
| Step 3. DIAGNOSE: Distinguish the presenting problem (visible symptom) from the root problem (underlying cause). Name the specific mechanism connecting them. One sentence each.                                                                                                                                                                                                                                                                                                                                        |
| Step 4. REFRAME: Propose 2 alternative problem statements - each sharper, more specific, and more falsifiable than the original. One sentence each, falsifiable, decision-relevant. Choose one and defend it in 2-3 sentences.                                                                                                                                                                                                                                                                                          |
| Step 5. CLOSE: Answer in one sentence each: (a) most important finding, (b) most important action, (c) biggest risk if nothing changes.                                                                                                                                                                                                                                                                                                                                                                                 |

| **\<task\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

| **\</task\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **\<methodology\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Every reframed problem must be falsifiable - state what evidence would prove it wrong. A problem you cannot be wrong about is not a problem statement.                                                                                                                                                                                                                                                                                                                                                                  |
| Name whose perspective anchors the reframe. In Saudi government: the Minister, Deputy Minister, and project manager frame the same situation very differently. Choose the decision-maker lens.                                                                                                                                                                                                                                                                                                                          |
| Test the reframed problem against Vision 2030 strategic urgency: does it represent a gap between this organisation current trajectory and what the national transformation agenda requires? If yes, state this explicitly.                                                                                                                                                                                                                                                                                              |
| Flag every inference. Distinguish observation from conclusion throughout.                                                                                                                                                                                                                                                                                                                                                                                                                                               |

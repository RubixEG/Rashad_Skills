# V6.1 Render Search and Exhibit Diversity Contract

Critical analytical pages must not jump from one chosen diagram description to a final master.

1. Generate exactly five materially distinct exhibit hypotheses.
2. Reject superficial rearrangements that preserve the same topology, focal hierarchy and reading path.
3. Select a hypothesis on analytical grounds.
4. Produce at least three rendered composition candidates for the winning hypothesis (or approved close variants).
5. Score actual rendered candidates using CEQS, Artifact Truth preservation, evidence proximity, spatial hierarchy, visual mass, readability and deck continuity.
6. Freeze only the highest valid candidate.

A single first render cannot be called `VISUAL_SEARCH_COMPLETE`.

# Failure Recovery + No-Unnecessary-Clarification Policy

STATUS: ACTIVE

## Do not ask when derivable
Do not interrupt the owner for information already available or safely derivable from current instructions, RFP/evidence, Owner Policy, current active authorities or approved defaults.

## Treat non-blocking unknowns as intelligence
When information is genuinely missing but does not block the current analytical product:
- record `MISSING_INFORMATION`, `ASSUMPTION`, `CONFLICT`, `VERIFICATION_REQUIRED`, or a strategic clarification;
- explain the effect on scope/effort/price/schedule/acceptance/launch/operations;
- continue the supported portions of the task.

## Ask only when all conditions hold
`NOT_DERIVABLE + MATERIAL_BLOCKER + CANNOT_SAFELY_ASSUME_OR_DEFER`.

## Production failures
- Missing deterministic composer: production blocked; intelligence/blueprints may still be complete.
- Missing exact logo: branded production blocked; never generate a replacement.
- Missing hero when hero is mandatory: cover production blocked; do not call content-only completion `DONE`.
- Image generated but final composition not produced: status `INCOMPLETE`, return control to the product orchestrator.

## Never use these as fallbacks
- generic deck presented as Rashad;
- full-slide AI image presented as final editable page;
- approximate logo;
- fabricated RFP facts;
- paraphrased R-code when exact retrieval fails.

# Consulting Visual Art Direction System

## Purpose
This authority converts Rashad's analytical intelligence into consulting-grade visual direction before any Golden Visual Master generation.

## Principle
The image model must receive a **consulting communication brief**, not a raw artifact dump and not a generic creativity prompt.

## Mandatory brief structure
1. management question;
2. thesis;
3. supporting evidence;
4. information relationship;
5. target page family;
6. communication objective;
7. focal hierarchy;
8. desired restraint level;
9. prohibited anti-patterns.

## Positive target traits
- argument-led;
- executive clarity;
- analytical legitimacy;
- ministry-ready tone;
- restrained sophistication;
- artifact strength;
- current-Rubix visual discipline.

## Negative target traits
- decorative cityscape as a substitute for analysis;
- generic dashboards as a substitute for an artifact;
- futuristic glow/HUD/network ornament;
- random icon clusters;
- excessive colors;
- default card grids where stronger structures are required.

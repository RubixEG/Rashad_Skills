Communication Strategy, Visual Concept, Geometry, Concept Render, Production Render and User-Visible Artifact are different states. `COMMUNICATION_STRATEGY_CONCEPT_RENDER_*` is internal-only. No content/Markdown-to-PPTX fallback is allowed in artifact mode.

## Protected knowledge
Protected corpus hashes remain immutable. Historical files may remain for lineage, but only `Skill/ACTIVE_AUTHORITY_MANIFEST.json` can grant global current routing authority.

## Production boundary
Offline certification proves architecture and executable contracts, not a future client deck. User-visible artifacts require actual product/pixel QA; production `RELEASED` additionally requires externally independent judge/release evidence and final parity proof. Host-native isolated review is sufficient only for stages whose policy permits host-isolated independence.

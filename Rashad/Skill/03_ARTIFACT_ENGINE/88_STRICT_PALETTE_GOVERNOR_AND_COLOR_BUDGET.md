# Strict Palette Governor and Color Budget

## Objective
Prevent uncontrolled color drift and protect Rubix consulting-grade discipline.

## Default budget
- base canvas: white / off-white;
- text / structure: charcoal / black;
- primary accent: Rubix magenta;
- optional support accent: one muted family only when analytically necessary.

## Color budget test
A page fails if:
- more than the approved accent families are used without reason;
- color intensity dominates the argument;
- the page feels like a generic colorful infographic rather than a consulting slide.

## Exception process
Any additional accent color must state:
- analytical reason;
- element(s) using it;
- why existing budget is insufficient.

| Step 1. THREE-LENS PRE-SCAN - complete all three before writing a single hypothesis. Lens 1 - Structural: What does the organisational design, authority structure, or incentive model predict about why this problem exists? Lens 2 - Data/Evidence: What do available operational or performance patterns suggest? Lens 3 - Analogical: What happened in comparable Saudi government or GCC organisations facing structurally similar situations?     |
| Step 2. GENERATE EXACTLY 5 HYPOTHESES using this structure for each - one must be labelled COUNTER-INTUITIVE: H (one direct falsifiable assertion with no hedging), Proof (specific data that confirms it), Disproof (specific data or event that kills it immediately), Likelihood (High/Medium/Low with one sentence reasoning), Fastest Test (how to validate within 48 hours).                                                                      |
| Step 3. SYNTHESIS: If the two highest-likelihood hypotheses are simultaneously true, what is the combined strategic implication?                                                                                                                                                                                                                                                                                                                        |
| Step 4. PRIORITY HYPOTHESIS: Which single hypothesis, if proven true, would most fundamentally change the strategic direction? Justify in 2 sentences.                                                                                                                                                                                                                                                                                                  |
| Step 5. VALIDATION SEQUENCE: In what order should hypotheses be tested? Which, if disproven, eliminates the most other hypotheses simultaneously?                                                                                                                                                                                                                                                                                                       |

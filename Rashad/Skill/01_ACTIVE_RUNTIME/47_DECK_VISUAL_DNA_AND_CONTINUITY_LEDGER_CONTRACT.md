# 47 — Deck Visual DNA & Continuity Ledger Contract

STATUS: HARD MULTI-PAGE CONTINUITY AUTHORITY — v2.6.4.4

## Purpose
Make 20–40 page image-generated decks coherent even when generation occurs page-by-page or across multiple continuation turns.

## Deck Visual DNA — freeze before page 1
Record:
- canvas/aspect ratio;
- light/dark rule and base surfaces;
- approved Rubix palette + controlled contextual-image variation;
- margins/safe zones;
- co-brand zone and optical geometry target;
- heading/body overlay zones;
- visual density curve across the deck;
- photo/illustration/rendering language;
- diagram/connector grammar;
- shape radius/stroke/shadow rules;
- accent-use policy;
- artifact-family rhythm;
- forbidden generic-card behavior;
- cover visual grammar;
- section opener grammar;
- evidence/table grammar;
- footer/page-number grammar.

## Style Anchor Set
Before mass generation, approve 3–5 actual visual anchors representing:
1. cover;
2. core analytical artifact;
3. dense evidence page;
4. technical/commercial page when applicable;
5. optional section opener/decision page.

Store their files/hashes as engagement visual references.

## Page Family Plan
Before page generation begins, assign every planned physical page a page family and visual-depth target. Do not improvise the deck family page-by-page.

## Continuity Ledger per page
Store:
- page_id;
- role_id/section_id;
- GVM mode;
- artifact family;
- page family;
- Style Anchor IDs;
- Section Anchor ID;
- previous/next page relation;
- generated master hash;
- composition summary;
- focal quadrant;
- density;
- dominant visual media;
- accent distribution;
- native overlay zones;
- continuity score;
- regenerate/freeze decision.

## Continue-turn rule
When generation continues after a pause/turn, rehydrate from the Style Anchor Set + Deck Visual DNA + Continuity Ledger. Never restart style from a text prompt alone.

## v2.6.4.6 executable continuity handoff
Every frozen master entry must include a resolvable file path and SHA-256, plus a Style Anchor/page-family anchor path when executable continuity fingerprinting is expected. The external v1.2 continuity checker emits `DECK_CONTINUITY_PASS` only from actual ledger/master evidence.

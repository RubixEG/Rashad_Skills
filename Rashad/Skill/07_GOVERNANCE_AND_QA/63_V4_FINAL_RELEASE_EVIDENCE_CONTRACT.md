# V4 Final Release Evidence Contract

`RELEASED` requires evidence IDs for:
- page-level executable DOM/pixel QA for every page;
- stress/predictive suite;
- topology/node/edge/label checks for artifact pages;
- font/BiDi checks;
- Golden Master fidelity or approved hybrid fidelity;
- PDF parity;
- PPTX parity;
- deck continuity/repetition;
- final council release.

If any required gate is `NOT_EXECUTED`, `FAIL`, `BLOCKED`, or merely `GATE_DEFINED`, final release is blocked.

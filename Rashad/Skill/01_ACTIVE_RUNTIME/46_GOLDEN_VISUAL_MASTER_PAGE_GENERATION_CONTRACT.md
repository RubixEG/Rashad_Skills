# 46 — Golden Visual Master Page Generation Contract

STATUS: HARD ACTIVE RUNTIME CONTRACT — v2.6.4.4

## Definition
`GOLDEN_VISUAL_MASTER` is a complete 16:9 visual composition generated for one approved page contract. It may contain the page's visual artifact, imagery, connectors, shapes, textures, spatial hierarchy and non-authoritative contextual scene content.

It is not the authority for final exact text or exact brand assets.

## Required sequence per page
1. lock page question/thesis/evidence/relationship;
2. lock Artifact Intent, nodes/edges and artifact family;
3. assign Page Family + Visual Depth;
4. load Deck Visual DNA + Style Anchor Set + Section Anchor + previous-page continuity reference;
5. generate one page master;
6. run Golden Master Council/QA;
7. freeze master hash and crop;
8. place it as a fixed underlay;
9. overlay exact native Arabic/English copy, **approved numerals under current language/numeral authority (Arabic-Indic for Arabic client-facing natural-language content)**, exact Rubix/client logos, page number and source labels;
10. run executable QA and export parity.

## Production master modes
- `GVM-COVER` — complete cover visual composition with identity-safe overlay zones.
- `GVM-ANALYTICAL` — relationship-led consulting visual/master artifact.
- `GVM-DENSE` — dense evidence/BOQ/team/evaluation visual structure with native overlay zones.
- `GVM-TECHNICAL` — technical/data/integration/commercial architecture visual master.

## Content treatment
The master may include non-authoritative abstract/stylized visual text on devices/signage when contextual. It must not contain the exact proposal copy/brand identity that the final overlay owns.

## Master immutability
After approval, the final compositor may not redraw, reinterpret, simplify, recolor, crop, mirror, or replace the master. It may add only approved overlay layers and micro masks needed to ensure readable native text.

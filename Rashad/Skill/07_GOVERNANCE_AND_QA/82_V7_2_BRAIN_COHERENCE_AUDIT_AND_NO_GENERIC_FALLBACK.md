# V7.2 — Brain Coherence Audit & No-Generic-Fallback Quality Law

**STATUS: CURRENT V7.2 GLOBAL COHERENCE / QUALITY AUTHORITY**

## Purpose
Prevent a formally certified Rashad package from producing a weak user-visible deck because rules existed only as prose, an old authority remained routable, SMEs were registered but never invoked, or QA certified the framework rather than the actual output.

## Mandatory audits before an offline baseline is called current
- line-by-line current-authority conflict scan;
- exact manifest path/binding validation;
- current-vs-lineage status scan;
- Brain role/council registry ↔ router ↔ runtime invocation parity;
- Artifact council registry ↔ routing ↔ executable invocation parity;
- communication-strategy parity across registry/runtime/constitution;
- user-visible delivery gate reachability and bypass attacks;
- QA Brain routing and execution coverage;
- Arabic RFP Summary routing check, including Arabic/RTL Artifact and QA councils;
- AI/technical RFP routing check, including AI Engineering / Data / Architecture / Cyber expertise;
- generic equal-card grid / shape-only deck rejection;
- real-RFP-shaped golden end-to-end acceptance;
- randomized stress and repeated-run determinism.

## Product quality hard failures
A multi-page analytical deck fails if production collapses into repeated equal-card grids, generic rectangles-and-text pages, repeated structural fingerprints, excessive diagram use, or communication-strategy claims not evidenced by the actual PPTX structure/pixels.

## QA closed loop
`Actual pixels → independent review → actionable repair brief → re-render → re-review`. Framework/unit/stress PASS cannot substitute for this loop. Missing exact-output evidence is `BLOCK_DELIVERY`.

Every newly discovered production incident becomes a permanent regression attack.

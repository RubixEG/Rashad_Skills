# V4 Visual Thinking & Semantic Reconstruction Director

## Mission
Mirror the useful observable behavior of high-quality image generation without pretending access to hidden model reasoning: think globally across the canvas, search multiple compositions, judge visual hierarchy as a whole, and only then reconstruct the approved visual in deterministic production layers.

## Page process
1. Freeze strong content pack: question, thesis, evidence, interpretation, implication, sources.
2. Create 3–4 materially different whole-page concepts.
3. Condition concepts on the relevant MWAN/current-deck/proposal-corpus page-family references.
4. Council selects one composition.
5. Produce/approve a Golden Visual Master or equivalent full-page visual board.
6. Build a semantic reconstruction map: regions, content blocks, artifact nodes, edges, labels, visual layers, z-order, alignment, and intentional whitespace.
7. Reconstruct in HTML/CSS/SVG where fidelity can be preserved.
8. If native reconstruction causes cardification or semantic/visual loss, use hybrid raster underlay + exact native text/brand overlays.
9. Instrument all production objects for executable QA.

## No premature geometry
Coordinates are not frozen until the concept is approved. Geometry exists to project the approved visual, not to discover it.

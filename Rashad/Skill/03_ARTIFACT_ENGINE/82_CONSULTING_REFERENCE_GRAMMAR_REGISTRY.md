# 82 — Consulting Reference Grammar Registry

These are abstract page grammars learned from accepted/internal proposal patterns and MWAN-quality benchmarking. They are not templates and contain no client facts.

- CRG-01 Answer-first executive thesis + one dominant decision artifact + implication rail.
- CRG-02 Need → objective → outcome architecture with causal carriers.
- CRG-03 Strategic pillar / capability architecture with cross-cutting enablers.
- CRG-04 Scope/workstream operating system with dependencies and acceptance outputs.
- CRG-05 Phase-gate / lifecycle with governance and feedback closure.
- CRG-06 Multi-track delivery roadmap with milestones, dependencies and decision gates.
- CRG-07 BOQ compression → cost driver → acceptance mapping.
- CRG-08 Technical/data/integration system architecture with directional islands.
- CRG-09 Team readiness / capacity / mobilisation evidence architecture.
- CRG-10 Evaluation criteria → threshold → win logic → evidence.
- CRG-11 Qualification readiness and evidence coverage.
- CRG-12 Commercial exposure / assumptions / sensitivity decision exhibit.
- CRG-13 Reverse submission plan / proposal preparation Gantt.
- CRG-14 Contract delivery roadmap / mobilisation / hypercare / operations.
- CRG-15 Risk prioritisation → response ownership → residual exposure.
- CRG-16 Clarification A-vs-B consequence / scope-cost-schedule decision map.
- CRG-17 Governance / decision rights / escalation architecture.
- CRG-18 Current-to-target transformation with measurable outcome bridge.
- CRG-19 Stakeholder / beneficiary ecosystem and service journey.
- CRG-20 Executive bid decision cockpit combining conditions, exposures and actions.

Reference grammar can guide composition but may not override current evidence or force a page into a pre-existing shape.

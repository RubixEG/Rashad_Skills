# 63 — V6 Unified Runtime Constitution

## One executable route
`ENGAGEMENT_RESET → EVIDENCE_LEDGER → CONSULTING_CONTENT_PACK → RELATIONSHIP_GRAPH → ARTIFACT_TRUTH → EXHIBIT_SYNTHESIS → VISUAL_SEARCH → PRODUCTION_ROUTE → UNIFIED_QA → COMMON_FINAL_MASTER → PDF/PPTX PARITY → RELEASE`

No alternative global image-first, HTML-first, template-first or PIL/card-first route may silently take precedence.

## Required persisted objects
- Engagement State
- Evidence Ledger
- Page Content Pack
- Relationship Graph (schema-valid + referentially valid)
- Artifact Truth Plan
- Exhibit Hypothesis Set (minimum 5 on critical analytical pages)
- Winning Exhibit Spec
- Page Spec
- QA Expectations
- Pending Product State before any image-generation tool call
- QA evidence IDs and Release Evidence

## Image-last orchestration
Image generation can be used for cover/editorial hero or visual ideation, but it is the final tool action of the turn. All state, prompt brief, exact text exclusion, assets, expected next step and resume token are written first. A tool-imposed end-of-turn is `IN_PROGRESS`, never `DONE`.

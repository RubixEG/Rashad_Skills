## Logo rules
- Never generate, redraw, stretch, flip, recolor, outline, shadow, crop or distort a Rubix logo.
- Use current verified assets from `08_BRAND_CURRENT/assets/`.
- Preserve clear space and aspect ratio.
- Client logo is engagement-specific and never stored permanently in the skill.

## Arabic rules
Brand brochure numeral styling is **not** client-facing numeral authority. Current user override: Arabic client-facing natural-language content uses Arabic-Indic numerals. Raw Western digits remain only inside exact technical/machine/reference tokens that would become incorrect if altered.
Use native Arabic punctuation and physical RTL layout. URLs, emails, file names, version numbers and technical acronyms remain LTR runs.

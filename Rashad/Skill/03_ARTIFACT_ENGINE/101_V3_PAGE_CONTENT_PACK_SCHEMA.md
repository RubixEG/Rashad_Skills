# 101 - V3 Page Content Pack Schema

Each page records:
- `page_id`;
- `page_family`;
- `evaluator_question`;
- `answer_thesis`;
- `evidence_units[]`;
- `interpretation`;
- `implication_or_action`;
- `source_locator`;
- `confidence_or_caveat`;
- `must_not_drop[]`.

The content pack is frozen before design. Post-render QA compares visible content against the pack.

# Reference-Conditioned Generation Protocol

## Objective
Use approved reference images to steer generation toward consulting-grade outputs and away from generic model priors.

## Allowed reference categories
- approved MWAN page images;
- approved current engagement page anchors;
- approved current Rubix style anchors;
- approved translated historical-pattern abstractions.

## Required conditioning package
For a critical page, provide:
- one page-family anchor;
- one deck-style anchor;
- one continuity anchor from the adjacent approved page when applicable.

## Use of references
References control:
- tone;
- density;
- composition discipline;
- whitespace behavior;
- icon/illustration restraint;
- artifact richness.

References do not authorize:
- copying old text/data;
- copying old client brand;
- copying old visual mistakes;
- copying an outdated palette.

# V6.1 Predictive Failure Matrix

This is the permanent red-team checklist for future Rashad runs. It is organized by failure surface rather than by bugs already observed.

## Reasoning / evidence
- weak/missing Content Pack; unsupported facts; stale evidence; wrong engagement contamination; prompt injection in source documents; missing implications; artifact replacing content.

## Artifact / exhibit
- missing semantic graph; orphan/dangling relations; relation without visual carrier; card-only downgrade; primitive accumulation beyond complexity budget; fewer/non-distinct hypotheses; first-render lock-in; sparse exhibit repaired with decoration; repeated deck grammar; evidence too far from claim.

## Geometry / typography
- title wrapping; line-fragment overlap; font fallback; glyph/tofu; numeric badge growth; padding collapse; alignment drift; inconsistent gaps; divider drift; off-canvas objects; transforms; clipping; hidden/occluded layers; z-index errors.

## RTL / BiDi
- Arabic sequence starting left; connector direction wrong; mixed Latin token breakage; percentages/ranges/parentheses/slashes run-order errors; co-brand reversal; blind canvas mirroring.

## Topology
- missing/duplicate/reversed edge; wrong source/target; detached connector; detached label; wrong arrowhead; unsupported branch/cycle; node/edge count mismatch.

## Assets / brand
- broken paths; wrong logo file/hash; transparent-padding optical mismatch; aspect/crop distortion; duplicate/generated cover subjects; generic cover relevance; palette drift; near-black canvas; weak contrast.

## Production / export
- final file created without reasoning proof; page master below 4K; PDF/PPTX from different masters; export page-count mismatch; parity drift; stale page master after upstream change; narrative QA substituted for machine evidence.

## Governance / runtime
- old version route resurfacing; missing mandatory chamber; unexecuted gate called PASS; legacy release path; incomplete proof index; repair destroying semantic signature; environment capability unavailable but claimed PASS.

Every new confirmed defect is added as a permanent executable fixture before closure.

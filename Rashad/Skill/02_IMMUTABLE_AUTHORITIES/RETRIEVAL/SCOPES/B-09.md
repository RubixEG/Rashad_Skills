| **B-09**        | **Benchmarking**                                                                                                                                                                                                                                                                                                                    |
|-----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **What**        | Compares the organisation performance against specifically named peer organisations to establish performance gaps, identify best practices, and set improvement targets.                                                                                                                                                            |
| **Delivers**    | Benchmark analysis report, performance gap quantification, best practice identification, improvement targets, implementation recommendations.                                                                                                                                                                                       |
| **How**         | Peer group definition, KPI framework alignment, data collection from benchmarks, gap analysis, root cause analysis for gaps, target setting, improvement recommendation.                                                                                                                                                            |
| **Saudi & GCC** | GCC government benchmarks: UAE Government Excellence Programme data, Qatar national performance reports, NCHRM published metrics, Saudi Vision 2030 KPI dashboards. For private sector: use sector-specific GCC peer companies. Never present OECD or Western benchmarks as the primary reference for Saudi government engagements. |

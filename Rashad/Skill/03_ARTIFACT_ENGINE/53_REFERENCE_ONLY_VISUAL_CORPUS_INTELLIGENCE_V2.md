## Source
Uses the existing audited historical proposal reverse-engineering outputs in this skill, including the reference index and narrative/artifact/composition intelligence derived from the historical technical/financial proposal corpus.

The raw proposals remain external/reference-only. No legacy logo, theme, exact layout, client fact, screenshot, commercial value, or proprietary page is activated by this module.

- artifact families observed in real consulting proposals;
- section and page density patterns;
- executive visual rhythm;
- evidence layering;
- methodology / delivery narrative structures;
- table discipline;
- diagram sophistication;
- team / capability / governance presentation patterns;
- case-study proof rhythm;
- transition from understanding to solution to delivery to evidence;
- common historical weaknesses and anti-patterns.

## Lower-bound benchmark rule
For a comparable page role, the new Rashad page should not be materially weaker than the strongest applicable abstract benchmark family available from the audited corpus.

This rule compares **quality attributes**, not pixels or exact historical layout:
- analytical relationship;
- hierarchy;
- focal strength;
- density control;
- evidence integration;
- executive restraint;
- section rhythm.

## Prohibited use
Never copy or infer current production authority from historical:
- logos;
- fonts;
- colors;
- exact page coordinates;
- client-specific content;
- old footers/headers;
- screenshots;
- team or case claims;
- financial values.


# Visual Reasoning Functional Emulation Protocol

Mirror the useful observable strengths of image-generation composition:
- divergent concept search;
- whole-canvas gestalt;
- focal hierarchy;
- asymmetry when useful;
- purposeful negative space;
- visual rhythm;
- integration of image + artifact + evidence as one composition;
- iterative pixel-level critique.

Do not emulate failure modes such as fabricated text, arbitrary colors, generic sci-fi motifs or ungrounded decoration.

## Required thought board
`dominant idea | focal anchor | eye path | mass map | negative-space map | evidence zones | visual metaphor | density | tone | benchmark family | anti-patterns`.

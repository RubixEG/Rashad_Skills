# Historical Proposal Corpus Integration Gate

A historical proposal-derived pattern enters Rashad only when all conditions pass:

- raw proposal file remains outside portable core;
- old logo/theme/font/master is not copied;
- no historical client/project fact is transferred;
- exact layout/coordinates are not cloned;
- the extracted learning is expressed as an abstract narrative, relationship, archetype, composition rule or anti-pattern;
- it is compatible with current Artifact Intent, Brand, RTL and Production Firewall authorities;
- Council records `ACCEPT_ABSTRACT`, `MERGE_EXISTING`, `REFERENCE_ONLY`, or `REJECT`;
- QA confirms no existing v2.3 protected authority was weakened.

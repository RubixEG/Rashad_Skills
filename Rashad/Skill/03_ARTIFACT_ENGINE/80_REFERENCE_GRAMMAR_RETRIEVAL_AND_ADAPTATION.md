# 80 — Reference Grammar Retrieval & Adaptation

References are retrieved by **analytical intent**, not by client name or sector alone.

Query dimensions: evaluator question, topology, dominant relation, page family, governance/feedback/measurement flags, density band and decision type.

Extract only abstract grammar:
- page role;
- argument pattern;
- information relationship;
- dominant/supporting artifact grammar;
- focal logic;
- reading path;
- mass distribution;
- evidence density;
- image role;
- negative-space principle;
- anti-patterns.

Never copy old client facts, logos, names, exact text, exact layout or retired palette. Historical frequency is not quality; references can be negative examples.

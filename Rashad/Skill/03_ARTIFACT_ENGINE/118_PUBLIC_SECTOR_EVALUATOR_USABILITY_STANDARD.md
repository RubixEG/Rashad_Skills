
# Public-Sector Evaluator Usability Standard

Government procurement platforms support electronic submission and technical evaluation; the visual system must therefore work as a static digital document without animation, hover or presenter narration.

## Scanability test
- 5 seconds: page topic / thesis identifiable;
- 15 seconds: dominant relationship / result identifiable;
- 45 seconds: supporting evidence identifiable;
- 90 seconds: source, implication and required action identifiable where applicable.

## Evaluation usability
- clear hierarchy;
- explicit compliance/evidence location;
- stable page numbering;
- legible static rendering;
- no reliance on animation;
- no decorative complexity that slows verification.

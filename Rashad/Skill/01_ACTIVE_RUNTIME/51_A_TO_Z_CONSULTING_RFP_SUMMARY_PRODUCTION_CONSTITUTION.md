# A-to-Z Consulting RFP Summary Production Constitution

STATUS: LEGACY SPECIALIST CONTENT/PRODUCTION DETAIL — NOT CURRENT GLOBAL ROUTING AUTHORITY

## Purpose
One deterministic authority for the whole path from RFP evidence to consulting-grade HTML/PDF/PPTX. This constitution supersedes conflicting historical defaults about image-first vs native production while preserving both as controlled modes.

## Canonical end-to-end chain
`Engagement Reset → Full-pack ingestion → Evidence model → 24-role depth planning → Page Content Contract → Content Council → Artifact Necessity Decision → Visual Thought Board → exactly 5-hypothesis competition for critical analytical pages → Benchmark/Reference Conditioning → Visual Council → Relative Composition Blueprint → HTML/SVG/CSS Master Candidate → Browser Raster → Independent Visual Critique → Non-destructive Repair → Semantic/RTL/Brand/Stress QA → Deck-Level Continuity QA → PDF/PPTX Projection → Parity QA → Final Release Council`.

## Non-negotiable ordering
1. **Content comes before artifact.** A page cannot use visual design to hide missing analysis.
2. **Artifact comes before geometry.** Do not freeze x/y coordinates before concept selection.
3. **Global composition comes before micro-layout.** Think about the full page as one visual system.
4. **Safety/fit comes after meaning.** Repair may not drop, relabel, reverse, hide or weaken approved semantic content.
5. **Final release comes after pixels.** Source code or file existence is not proof of visual quality.

## Production modes
- `HTML_SVG_MASTER` — DEFAULT. Native HTML text + CSS macro-layout + SVG relationship geometry.
- `GVM_RASTER_MASTER` — explicit fidelity fallback or owner-selected visual-mirror mode when HTML/SVG cannot preserve the approved concept without material loss.
- `REFERENCE_IMAGE_ONLY` — visual ideation; never a released production page.

## Content / artifact rule
Every page is assigned one of:
- `EDITORIAL_EVIDENCE` — content-led; no dominant artifact required;
- `ARTIFACT_LED` — relationship-led artifact is essential;
- `HYBRID` — artifact plus substantial explanatory content;
- `DATA_TABLE` — a table is the legitimate artifact;
- `IMAGE_LED_OPENER` — cover/section opener only.

Artifacts are not mandatory merely to make a page look designed.

## Cover rule
Arabic/bilingual RFP Summary cover default:
- topic-specific consulting-grade editorial hero on physical left;
- clean native title/identity on right;
- exact `Rubix | Client` signature on one optical line on the left;
- hero passes semantic relevance, not just sector relevance.

## Release truth
A page may look beautiful and still fail if content is shallow, evidence is weak, topology is wrong, labels are detached, RTL is reversed, color is uncontrolled, or the cover image is semantically generic.

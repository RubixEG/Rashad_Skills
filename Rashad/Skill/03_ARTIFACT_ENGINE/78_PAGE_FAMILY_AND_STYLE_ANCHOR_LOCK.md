# Page Family & Style Anchor Lock

STATUS: HARD DECK-CONSISTENCY AUTHORITY — v2.6.4.4

## Page families
At minimum distinguish:
- Cover / opener;
- Executive synthesis;
- Snapshot / metric landscape;
- Strategic architecture;
- System/workstream architecture;
- Journey / phase-gate;
- Compression / mapping;
- Technical/data/integration architecture;
- Team capacity / role-to-output;
- Evaluation / criteria-to-win;
- Evidence/readiness;
- Commercial exposure;
- Gantt / critical path;
- Risk / clarification / assumption;
- Decision cockpit.

The family determines the visual grammar; it does not force a template.

## Continuity fingerprint
Each page is checked against the frozen anchor set for:
- surface/lightness;
- color temperature and accent logic;
- visual-material style;
- edge/stroke/shape language;
- typography reserve geometry;
- co-brand/footer geometry;
- density and whitespace;
- artifact sophistication;
- section rhythm.

## Drift handling
If continuity drifts, the preferred repair is to regenerate the page with stronger anchor conditioning, not to manually force it into generic cards.

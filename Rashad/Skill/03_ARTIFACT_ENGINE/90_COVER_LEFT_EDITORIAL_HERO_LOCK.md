# Cover Left Editorial Hero Lock

## Mandatory default
For Arabic and bilingual RFP Summary covers, the page uses:
- a **left-side consulting-grade editorial hero image** tied clearly to the engagement topic;
- a **right-side native content/identity zone** for title, subtitle, and identifiers;
- the co-brand signature on the left: `Rubix | Client`, both transparent-background PNGs, same optical height, same line.

## Hero requirements
The hero image should:
- be topic-relevant;
- look institutional and consulting-grade;
- avoid marketing gimmicks or generic sci-fi styling;
- create a calm, premium, executive impression;
- support, not overpower, the right-side message zone.

## Forbidden cover drift
- random multi-color futuristic scenes;
- weak client logo presence;
- misaligned co-brand logos;
- image-right default when no explicit override exists;
- generic cards embedded into the cover composition.

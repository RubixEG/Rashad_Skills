| **D-07**        | **Cybersecurity Strategy**                                                                                                                                                                                                                                                                                                                                |
|-----------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **What**        | Defines the organisation cybersecurity posture, risk framework, and security architecture.                                                                                                                                                                                                                                                                |
| **Delivers**    | Cybersecurity strategy, risk assessment, security architecture, security governance framework, security roadmap, incident response plan.                                                                                                                                                                                                                  |
| **How**         | Current state security assessment, threat landscape analysis, risk prioritisation, security architecture design, governance framework development, capability gap assessment.                                                                                                                                                                             |
| **Saudi & GCC** | Saudi cybersecurity strategy must comply with the National Cybersecurity Authority (NCA) Essential Cybersecurity Controls (ECC) and Critical Systems Protection Controls (CSCC). Government entities and critical infrastructure operators have mandatory NCA compliance requirements. SAMA cybersecurity framework applies to financial sector entities. |

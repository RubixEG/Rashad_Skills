# Reference Retrieval by Analytical Intent

Retrieve references by **analytical problem**, not by client name or sector alone.

Examples:
- team readiness → capability/readiness/capacity references;
- evaluation → threshold/criteria-to-win/scoring references;
- scope → operating-system/layer/value-chain references;
- risk → heatmap/register/dependency/exposure references;
- governance → ownership/decision/escalation references.

For each retrieved reference extract only:
- page role;
- information relationship;
- semantic topology;
- composition grammar;
- reading path;
- focal point;
- density behavior;
- reusable principle;
- anti-pattern.

Never import old client facts, logos, claims, exact layout or outdated brand as current authority.

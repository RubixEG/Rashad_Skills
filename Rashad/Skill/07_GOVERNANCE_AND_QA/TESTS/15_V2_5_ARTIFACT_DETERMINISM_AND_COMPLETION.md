# V2.5 Artifact Determinism & Completion Regression Tests

1. Authority (superseded by v2.6.4.5): the owner-locked Final Canonical Proposal Skeleton controls proposal architecture. Mandatory RFP forms/order requirements are mapped or supplemented; irreconcilable conflicts block rather than auto-change the skeleton.
2. Selector: every REL-* including REL-CAUSE/REL-VAL/REL-QUANT routes to candidate archetypes; selection records scores/tie-breaks.
3. Composite: two material relationships with no >=80 single fit produce COMPOSITE_BESPOKE, not a forced catalog slide.
4. Vocabulary: active ledgers persist only FULLY_NATIVE/VECTOR_HYBRID/RASTER_AUGMENTED; historical aliases are not persisted.
5. Geometry: every production geometry object has contract_id/version/status/source blueprint hash/session/approval/lock hash and ledger entry.
6. Staleness: upstream Intent/Blueprint hash change marks Geometry Handoff STALE.
7. Product router: `RFP Summary` routes to INTERNAL_PURSUIT_BRIEF + ARTIFACT by default.
8. Content-only exception: only explicit user request can satisfy a content-only route.
9. Cover asset: generated hero remains a substep; product state cannot complete after hero generation.
10. Arabic cover: image zone left, native identity/text zone right unless explicit user override.
11. Capability: generic image/HTML/document tools do not imply deterministic composer availability.
12. Blocked production: unavailable composer results in BLOCKED product with completed/incomplete stage report, not DONE.
13. Strict hero: production hero contains zero text/logo/number/fact pixels by brief contract.
14. Logo QA: validate provenance/aspect/crop/recolor/clear-space/minimum-size, never post-resize pixel equality.
15. Release: final completion requires actual final artifact refs + QA PASS + release approval.

| **\<thinking_instructions\>**                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Step 1. DECISION ANCHOR: What specific decision will this tree inform? Write it as one question with a named decision-maker. Every branch must connect to this decision or be removed.                                                                                                                                                                                                                                                                          |
| Step 2. LEVEL 1 CANDIDATES: Generate the natural mutually exclusive groupings. For each bucket: if this contained the answer, what would we do differently? If the answer is nothing, it does not belong.                                                                                                                                                                                                                                                       |
| Step 3. COMPLETENESS CHECK: Is there any scenario where the answer lives outside all Level 1 buckets? If yes, restructure before proceeding.                                                                                                                                                                                                                                                                                                                    |
| Step 4. BUILD THE TREE: Level 1 (3-5 buckets) and Level 2 (2-4 sub-issues per bucket). For each L1 bucket: the key question it answers, the most important sub-issue, and the data needed to resolve it.                                                                                                                                                                                                                                                        |
| Step 5. PRIORITY BRANCH: The single branch most likely to contain the decisive answer. Justify in 2 sentences with specific reasoning.                                                                                                                                                                                                                                                                                                                          |
| **\</thinking_instructions\>**                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **\<task\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Build a two-level MECE issue tree. Complete all five steps before producing final output.                                                                                                                                                                                                                                                                                                                                                                       |
| **\</task\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **\<methodology\>**                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Design the issue tree backwards from the decision it must inform, not forwards from the problem description.                                                                                                                                                                                                                                                                                                                                                    |
| MECE self-test: can every piece of evidence be placed in exactly one branch? If evidence fits two branches, restructure.                                                                                                                                                                                                                                                                                                                                        |
| For Saudi government diagnostic engagements, apply the default Level 1 structure: Strategic / Operational / Enabler. Override only when evidence demands otherwise.                                                                                                                                                                                                                                                                                             |
| Always test whether a Strategic Alignment with Mandate branch belongs at Level 1. In government contexts this frequently contains the highest-leverage issues.                                                                                                                                                                                                                                                                                                  |
| Add Regulatory and Governance Compliance as a mandatory Level 1 candidate for any government entity or regulated sector engagement.                                                                                                                                                                                                                                                                                                                             |

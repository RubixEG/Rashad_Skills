# 81 — Exhibit-to-Production Handoff

The winning Exhibit Spec is the production design contract.

Native HTML/CSS/SVG is used when it can preserve the approved topology and composition. Governed Hybrid GVM + native exact text/brand is used when native reconstruction would materially weaken the approved exhibit. Editability never outranks fidelity.

The handoff freezes:
- content signature;
- graph hash;
- node/edge set;
- spatial carrier mapping;
- exhibit hypothesis ID;
- evidence packing map;
- focal hierarchy;
- directional zones;
- brand assets;
- QA expected counts;
- image-last pending state when applicable.

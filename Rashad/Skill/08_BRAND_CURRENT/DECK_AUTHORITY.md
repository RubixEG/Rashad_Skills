# Deck Authority — Artifact-Safe Cutover

The brand/deck supplied on 2026-08-11 is a **visual evidence source**. It does not control proposal logic or force layouts.

## Visual authority precedence
1. Current explicit user visual instruction.
2. Current Rubix normalized brand authority in `08_BRAND_CURRENT/`.
3. Artifact Intent and semantic relationship.
4. Current engagement client identity and any client-mandated visual constraints.
5. Historical proposal visual intelligence as reference-only.
6. Old deck/builders/templates: never production authority.

## Hard rules
- 16:9 canvas for slide artifacts unless the user requests another format.
- Light-first canvas.
- **No black or near-black slide background.**
- No default Office theme.
- No fixed template may replace an artifact family selected from information meaning.
- Current logos only.
- Cover uses a generated hero image but keeps all text/logos/native identifiers editable.

# 75 — Spatial Semantics & Visual Carrier Grammar

Semantic relationships carry preferred and forbidden spatial encodings.

| Relation | Preferred spatial encoding | Forbidden default |
|---|---|---|
| ENABLES | foundation, feeder, underlay, inward support | equal peer cards |
| DEPENDS_ON | prerequisite chain, upstream anchor, dependency bridge | disconnected list |
| FLOWS_TO | explicit progression, path, transition | unordered grid |
| CONTROLS | enclosure, supervisory plane, cross-cutting band | peer box |
| MEASURES | attached gauge/indicator/evidence axis | floating KPI unrelated to target |
| EVIDENCES | near-claim proof, source/evidence rail | distant footnote only |
| RISKS | exposure field/heat map/overlay | flat risk cards if prioritisation exists |
| PRIORITIZES | ranked field/funnel/decision axis | equal-sized peers |
| OWNS | ownership lane/anchored role | decorative avatar |
| APPROVES | gate/choke point/decision node | plain arrow |
| FEEDS_BACK | visible closed return path | implied feedback text |
| THRESHOLD_FOR | cut line/gate/gauge | unanchored percentage |
| MAPS_TO | matrix/paired bridge | separate lists |
| BLOCKS | barrier/choke point/constraint edge | note floating aside |

The renderer must not replace a preferred carrier with a forbidden encoding unless the Exhibit Council documents a justified exception.

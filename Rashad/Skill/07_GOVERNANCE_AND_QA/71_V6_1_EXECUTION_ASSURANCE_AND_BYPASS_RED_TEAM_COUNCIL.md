Mandatory adversarial questions:
- Can a final image be produced without a Content Pack?

- Can fewer than five hypotheses reach selection?
- Can a single render be called visual search?
- Can CEQS be asserted without an evidence report?
- Can a narrative QA report substitute for machine evidence?
- Can an old startup route be retrieved as CURRENT?
- Can changing upstream content leave stale downstream PASS evidence?
- Can PDF/PPTX release without product Proof Index?

Any YES = NO-GO.

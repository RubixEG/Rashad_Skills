| **\<thinking_instructions\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Step 1. SITUATION: Write 2-3 sentences describing the current state everyone in the room already knows and agrees on. No new information - shared factual baseline only. Include one key number. If any sentence could be disputed, it belongs in the Complication.                                                                                                                                                                                                                                                                   |
| Step 2. COMPLICATION: Write 2-3 sentences introducing the specific tension - what has changed, deteriorated, or become urgent that makes the current situation no longer acceptable? Include quantified stakes. Apply the inaction test: could a rational decision-maker hear this and still choose to do nothing? If yes, rewrite it until the answer is no.                                                                                                                                                                         |
| Step 3. RESOLUTION QUESTION: The single question the complication demands be answered. Must be: answerable (not rhetorical), falsifiable (could be answered do nothing), and specific enough to anchor the entire analysis.                                                                                                                                                                                                                                                                                                           |
| Step 4. QUALITY TEST - four tests, all must pass: (a) Does the Situation contain only universally agreed facts? (b) Does the Complication follow logically from the Situation? (c) Does the Resolution question follow directly from the Complication? (d) Would the primary decision-maker understand the full narrative in 45 seconds?                                                                                                                                                                                              |
| Step 5. ALTERNATIVES: Write one alternative SCR framing for a resistant audience. Identify the single most important word in the Complication to change to sharpen urgency.                                                                                                                                                                                                                                                                                                                                                           |

| **\</task\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **\<methodology\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| The most common SCR failure: the Complication contains analysis or recommendations. It should contain only the tension - the specific change or deterioration that makes the current state unacceptable.                                                                                                                                                                                                                                                                                                                              |
| For Saudi government: the Situation paragraph must acknowledge the organisation achievements and the sponsor stated vision before introducing the Complication. Begin with the progress then name the gap that threatens it. This sequencing is not optional in Saudi ministerial communication.                                                                                                                                                                                                                                      |
| The Complication must quantify stakes. Service quality is declining is not a Complication. Citizen service cycle times have increased 34% in 18 months, placing the ministry 47% below the NCHRM excellence standard ahead of the Q2 national performance review is.                                                                                                                                                                                                                                                                  |
| For GCC private sector: the Complication framing that lands hardest is typically competitive threat and ownership return risk.                                                                                                                                                                                                                                                                                                                                                                                                        |
| **\</methodology\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **\<output_format\>**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

One alternative framing for resistant audience. One word to sharpen. Total: maximum 6 sentences for the full SCR.                                                                                                                                                                                                                                                   |

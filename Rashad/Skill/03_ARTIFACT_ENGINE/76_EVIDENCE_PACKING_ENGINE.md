# 76 — Evidence Packing Engine

When a page is visually sparse, the default response is **add useful evidence, not decoration**.

Rank available evidence by:
1. evaluator relevance;
2. decision consequence;
3. relationship explanatory value;
4. source confidence;
5. uniqueness (avoid repetition across pages).

Permitted evidence inserts include stage outputs, acceptance criteria, ownership, KPIs, thresholds, risks, decision conditions, quantified commitments, source-backed facts and caveats.

Evidence must sit close to the claim or artifact element it proves. Decorative icons, generic photos, extra cards, ornamental lines or duplicate text may not be used merely to increase visual fill.

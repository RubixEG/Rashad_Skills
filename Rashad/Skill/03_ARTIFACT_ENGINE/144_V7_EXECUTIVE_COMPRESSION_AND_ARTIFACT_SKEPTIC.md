# V7 — Executive Compression & Artifact Skeptic

**STATUS: INHERITED FOUNDATION — CURRENT EXECUTION ROUTES THROUGH V7.2 ARTIFACT BRAIN**

## Executive compression
Reduce cognitive load by removing duplication, merging redundant labels, prioritizing decision-relevant evidence and splitting dense pages. Never shrink below readability or delete material evidence/topology to fit.

## Skeptic attacks before render
- What does this page actually conclude?
- Could the same layout be used for an unrelated client with only text swapped? If yes, likely generic.
- Are relationships visible or merely described?
- Are peer objects accidentally equal when importance differs?
- Is hierarchy intentional and evidence-backed?
- Does the evaluator/CEO understand the implication in 5–10 seconds?
- Is the artifact doing analytical work or decorating text?
- Does it repeat the deck's previous topology without analytical reason?

Failure returns to synthesis, not to a weaker card layout.

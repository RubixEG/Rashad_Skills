# Visual Concept Competition Director

Before final generation, create multiple page concepts and choose deliberately.

Required process:
- generate 3–4 distinct consulting concepts for the page;
- each concept must represent a different analytical framing or composition strategy;
- score concepts against clarity, consulting strength, ministry suitability, artifact strength, and continuity with the deck;
- select one winning concept before generation.

The selected concept is binding for the generation brief unless council escalation reopens the choice.

This prevents the system from treating the first acceptable-looking concept as the page truth.

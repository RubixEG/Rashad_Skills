# PDF / PPTX Projection from HTML Master

## Default route
`approved HTML/SVG/CSS master → browser raster / PDF → visual-mirror PPTX`.

### PDF
Use the approved fixed-canvas HTML as the source. Export without responsive reflow.

### PPTX visual mirror
Use the approved page raster as a full-slide image to preserve visual fidelity.

### Editable PPTX
Optional secondary workstream. Reconstruct from semantic contracts and compare against the HTML master. Do not degrade the official visual output merely to claim editability.

### HTML
The approved HTML/SVG/CSS itself is a first-class deliverable when requested.

# V7.0.1 — RFP Management/Bid Decision Evidence Contract

**STATUS: LINEAGE / COMPATIBILITY ONLY — current routing uses `74_V7_RFP_BID_DECISION_EVIDENCE_CONTRACT.md` under v7.0.2**

The final RFP Summary recommendation is a management decision-support synthesis, not a model vote and not an automatic weighted score. Validate the decision object against `schemas/rfp_bid_decision_evidence_v7_0_1.schema.json`.

All ten decision dimensions must be represented with assessment, confidence, rationale and source-located evidence. `GO_WITH_CONDITIONS` requires explicit conditions; `HOLD` requires blockers; `INSUFFICIENT_INFORMATION` must declare insufficient evidence. A counter-case is mandatory so the Council demonstrates that it challenged the recommendation.

The output remains a Rashad/Council recommendation requiring management approval. Do not convert uncertain qualitative judgments into fabricated precision. Hard compliance/legal/evidence blockers cannot be averaged away by favorable dimensions.

# Consulting Composition Search Engine

## Objective
Search for the strongest spatial composition, not merely the correct artifact label.

## Candidate composition families
- editorial split;
- dominant-center + evidence rail;
- central hub + governed satellites;
- layered operating architecture;
- value-chain spine + enabling bands;
- circular lifecycle with gate overlays;
- decision cockpit;
- matrix + interpretation panel;
- horizontal journey + evidence bands;
- portfolio landscape;
- evidence-to-decision chain;
- executive synthesis with one dominant number/decision.

## Selection criteria
- argument clarity;
- analytical relationship fit;
- visual hierarchy;
- density suitability;
- RTL readability;
- benchmark fit;
- implementation feasibility in HTML/SVG/CSS.

No concept wins merely because it is easiest to code.

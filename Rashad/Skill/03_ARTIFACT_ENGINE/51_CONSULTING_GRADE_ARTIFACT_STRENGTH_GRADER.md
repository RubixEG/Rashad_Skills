# Consulting-Grade Artifact Strength Grader — Extension to ART-NR-001

STATUS: ACTIVE / DOES NOT REPLACE `20_ARTIFACT_STRENGTH_NON_REGRESSION_AUTHORITY.md`

## Purpose
Add a consulting-grade quality lens to the existing Artifact Strength score without creating a competing vocabulary.

## Questions
- Does the selected artifact reveal a relationship the evaluator needs to understand?
- Does it contain structural insight, not just formatted content?
- Does hierarchy show what matters most?
- Does it make dependencies, sequence, ownership, causality, evidence or trade-offs visible when relevant?
- Would replacing it with cards/table/list materially reduce understanding?
- Is it stronger than a generic presentation layout?

## Consulting-grade artifact indicators
Strong examples include, when supported by evidence:
- operating model architecture;
- capability stack;
- value chain;
- service blueprint;
- governance and decision architecture;
- delivery wave / phase-gate plan;
- BOQ compression and acceptance map;
- criteria-to-win architecture;
- risk prioritization and response model;
- dependency network;
- stakeholder alignment map;
- team capacity / role-to-output architecture;
- delivery control tower;
- readiness ladder;
- evidence-to-decision chain;
- implementation/change journey;
- contractual-obligation intelligence view.

## Hard fail
A relationship-heavy page that is visually polished but analytically equivalent to a decorative card grid fails this grader.

This grader feeds the existing ART-NR-001 score; it does not reduce existing thresholds.

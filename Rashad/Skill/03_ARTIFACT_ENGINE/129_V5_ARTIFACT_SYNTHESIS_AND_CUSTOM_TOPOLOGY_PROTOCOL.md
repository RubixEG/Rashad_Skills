# Artifact Synthesis & Custom Topology Protocol

## Purpose
Rashad is not limited to a catalog of artifact templates. The catalog is a vocabulary/reference library, not a ceiling.

## Synthesis method
1. Identify the dominant relationship pattern in the graph.
2. Identify secondary relationships that materially change interpretation.
3. Determine whether one artifact can explain both; if not, build a composite page.
4. Create topology candidates using nodes, edges, bands, loops, rails, thresholds, layers, matrices, sequences, ownership zones and feedback structures.
5. Reject a concept if it merely renames a grid of equal boxes.
6. Preserve evidence proximity: claims and supporting evidence remain visually near the relationship they justify.
7. Freeze topology only after council selection.

## Custom artifact permission
A new artifact structure is allowed and preferred when it explains relationship truth better than existing families. Record its semantic topology so QA can validate it even if the visual form is novel.

# 77 — Whole-Canvas Visual Search Engine

The system must reason over the whole 16:9 canvas before exact geometry.

For each exhibit hypothesis define:
- visual mass map (4×4 minimum mental model);
- dominant mass share;
- focal point and secondary focal point;
- eye path / scan order;
- evidence proximity;
- asymmetry target;
- negative-space allocation;
- title-to-artifact hierarchy;
- intended page tempo.

Equal-size/equal-weight treatment of semantically unequal nodes is a failure. Node area, label prominence and position should reflect strategic importance, decision weight and relationship role.

# 37 — Artifact Production Orchestrator

STATUS: **HARD ORCHESTRATION AUTHORITY — v2.5**
PURPOSE: Ensure Artifact Intelligence, image assets, deterministic composition and QA execute as one product pipeline.

## Pipeline
```text
USER REQUEST
→ PRODUCT ROUTER
→ DELIVERY / COMPLETION CONTRACT
→ RFP / CONSULTING ENGINE
→ CONTENT MODEL
→ PAGE CONTRACTS
→ RELATIONSHIP CLASSIFIER
→ DETERMINISTIC ARCHETYPE SELECTOR
→ ARTIFACT INTENT LEDGER
→ ARTIFACT COUNCIL
→ VISUAL BLUEPRINT LEDGER
→ ASSET PLAN
→ IMAGE GENERATION (only if required)
→ GEOMETRY HANDOFF LEDGER
→ CAPABILITY PREFLIGHT
→ PRODUCTION FIREWALL
→ DETERMINISTIC COMPOSER
→ BRAND / LANGUAGE / RTL / NUMERAL LAYER
→ SEMANTIC + TOPOLOGY + VISUAL + GEOMETRY + RTL + NUMERAL + BRAND QA
→ RELEASE COMPLETION GATE
→ FINAL FILE DELIVERY
```

## Mandatory control return after tool substeps
Every asset-generation or external production substep returns control to this orchestrator. No substep may terminate a product request by itself.

## Page minimum before composition
`PAGE_ID, PAGE_ROLE, EXECUTIVE_QUESTION, THESIS, EVIDENCE, DOMINANT_RELATIONSHIP, ARTIFACT_INTENT, SELECTOR_DECISION, ARCHETYPE, SEMANTIC_NODES, SEMANTIC_EDGES, FOCAL_POINT, READING_PATH, EDITABILITY_CLASS, IMAGE_MODE, VISUAL_BLUEPRINT, GEOMETRY_HANDOFF`.

## Fail closed
Do not fall back to text completion, full-slide generated imagery, generic cards, generic deck/HTML, or approximate brand when the routed product requires an artifact.

## v2.6.4.4 Golden Visual Master execution branch
After Artifact/Visual Excellence approval, choose `GOLDEN_VISUAL_MASTER` whenever available and likely to preserve visual quality better than native reconstruction. Generate/freeze one page master, then return to the orchestrator for native overlay, executable QA, export and release. The image result alone is never DONE.

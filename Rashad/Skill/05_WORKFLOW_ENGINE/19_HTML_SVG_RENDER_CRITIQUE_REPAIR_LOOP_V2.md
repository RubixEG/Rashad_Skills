
# HTML/SVG Render → Critique → Repair Loop v2

`candidate DOM → fonts ready → layout/RTL → SVG routes → raster → critique → compare signatures → repair → reraster`.

Critique order:
1. content completeness;
2. page argument;
3. macro composition;
4. artifact strength;
5. evidence placement;
6. typography;
7. RTL/BiDi/topology;
8. color/brand;
9. micro-alignment.

Repair must preserve semantic signatures.

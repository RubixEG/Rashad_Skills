
# Deck-Level Visual Rhythm & Repetition Control

## Objective
Keep 20–40 page decks coherent without becoming repetitive.

## Track
- page family sequence;
- dominant composition family;
- density class;
- image/artifact/table ratio;
- palette usage;
- repeated structural signature;
- section anchor.

## Rules
- more than two consecutive pages with the same equal-card/grid grammar requires explicit justification;
- major analytical roles should not all use the same composition family;
- repeated visual devices are allowed when they create house rhythm, not when they replace analysis;
- section anchors may repeat; analytical artifacts should vary by relationship.

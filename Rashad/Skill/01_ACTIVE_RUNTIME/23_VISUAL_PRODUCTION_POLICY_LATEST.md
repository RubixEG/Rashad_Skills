# Legacy Visual Production Policy — v2.6.4.10 Consolidated

## Legacy default preserved for lineage; current production route is resolved by v6.2.2 manifest
**VERSION 4 SUPERSESSION:** final analytical-page production mode is fidelity-based. Use semantic-native HTML/SVG only when it preserves the approved Golden Visual Master/whole-page visual board; otherwise use governed hybrid GVM+native overlays.

## Image generation
Image generation may:
- produce topic-specific cover/section imagery;
- support divergent visual concept ideation;
- create reference compositions;
- serve explicit `GVM_RASTER_MASTER` fallback when HTML/SVG cannot preserve the approved concept.

It does not own factual text, logos, official values or source truth.

## Analytical production order
`content pack → artifact necessity → visual concept search → benchmark/reference conditioning → HTML/SVG/CSS candidate → browser raster → visual/content critique → non-destructive repair → QA → freeze master → PDF/PPTX projection`.

## Geometry
Semantic nodes/edges may be known early; exact physical geometry is frozen only after concept selection and initial render critique.

## Hero replacement
Cover hero changes may not silently change title, brand, content or page geometry unless the cover concept itself is deliberately reopened.

## No downgrade
If a safety/renderer limitation would force semantic loss, split or redesign upstream. Do not convert a strong artifact into generic cards merely to pass fit checks.

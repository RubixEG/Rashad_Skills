# Browser Critique, Repair & Export Workflow

1. Render HTML at fixed canvas.
2. Capture raster screenshot.
3. Run mechanical QA: overflow, collision, font, RTL, logos, bounds.
4. Run consulting visual critique and CVFS.
5. Repair locally.
6. Rerender.
7. If still < threshold after 3 cycles, return to concept selection.
8. Freeze approved HTML master.
9. Export PDF.
10. Create PPTX visual mirror.
11. Run cross-format parity.
12. Deck-level rhythm/continuity council.
13. Release.

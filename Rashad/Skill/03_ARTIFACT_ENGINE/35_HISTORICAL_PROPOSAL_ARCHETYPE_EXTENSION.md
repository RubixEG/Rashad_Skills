# Historical Proposal Artifact Archetype Extension

STATUS: ACTIVE EXTENSION TO `26_VISUAL_ARCHETYPE_LIBRARY_V1.md`

These archetypes were abstracted from historical proposal patterns. They do not carry historical brand, exact layouts or client facts.

| ID | Archetype | Best used when | Required semantic content | Common failure |
|---|---|---|---|---|
| H-01 | Strategic Pillar Architecture | few pillars drive one outcome | pillars + outcome + causal/enablement relation | equal decorative pillars with no relation |
| H-02 | Multi-Track Delivery Architecture | parallel tracks share gates/milestones | tracks + dependencies + gates | independent cards |
| H-03 | Phase Journey with Output Gates | delivery evolves through phases | phase purpose + outputs + gate | named phases only |
| H-04 | Capability / Operating Model Hierarchy | capabilities have levels | layers + ownership/role relation | org-chart styling without operating logic |
| H-05 | Current-to-Target Transformation | change from diagnosed state | current evidence + gap + target capability + transition | generic before/after |
| H-06 | Deliverable / Milestone Roadmap | outputs occur across time | deliverables + timing + acceptance/owner | timeline decoration |
| H-07 | Governance & Decision Architecture | governance must control delivery | bodies + decisions + cadence + escalation | boxes without decision rights |
| H-08 | Case Study Proof Panel | evidence must support a claim | claim + proof + result + relevance | screenshot wall |
| H-09 | Stakeholder / Ecosystem Map | actors interact materially | actors + role/flow/influence | logo wall |
| H-10 | Executive Metrics Snapshot | a few numbers prove/guide a decision | metric + context + implication | number wallpaper |
| H-11 | Workstream-to-Deliverable Matrix | outputs span workstreams | workstream + deliverable + owner/acceptance | lookup table with no prioritization |
| H-12 | Section Navigation / Rhythm Device | long proposal needs orientation | section promise + navigation cue | decorative divider with no thesis |

Selection still starts with the current page question and information relationship. These are candidates, never defaults.

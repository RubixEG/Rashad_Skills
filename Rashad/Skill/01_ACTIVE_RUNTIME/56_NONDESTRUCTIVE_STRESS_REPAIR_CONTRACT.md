
# Non-Destructive Stress Repair Contract

STATUS: HARD SAFETY / REPAIR AUTHORITY — v2.6.4.10

Stress and safety checks protect production quality but may never weaken approved intelligence.

## Immutable semantic signatures
Before stress repair freeze:
- `content_signature` — approved visible content / claims / implications / sources;
- `topology_signature` — node IDs + edge IDs + source/target + relationship type;
- `brand_signature` — approved asset hashes / logo order;
- `direction_signature` — page direction + sequence semantics + no-mirror zones.

After any automatic repair, recompute signatures. Unexpected change = **REPAIR_SEMANTIC_REGRESSION → BLOCKED**.

## Allowed repair ladder
1. micro spacing/alignment;
2. local line-break optimization;
3. local region growth/rebalancing;
4. connector rerouting without semantic change;
5. controlled composition rebalance;
6. page split preserving all content/topology;
7. return upstream for redesign.

## Forbidden repair
- delete evidence;
- drop/reverse an edge;
- hide a label;
- collapse system into cards;
- remove source trace;
- globally shrink until unreadable;
- mirror an image/logo/technical island incorrectly.

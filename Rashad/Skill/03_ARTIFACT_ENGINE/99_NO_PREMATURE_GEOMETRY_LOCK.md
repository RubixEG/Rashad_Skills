# No Premature Geometry Lock

## Problem
Exact x/y geometry too early can freeze a mediocre composition before holistic visual search is complete.

## New stage order
1. Semantic Lock — facts, thesis, nodes/edges, evidence.
2. Visual Thought Board — no exact x/y.
3. Concept Competition — no exact x/y.
4. Visual Council selects a composition.
5. Composition Blueprint — relative zones/proportions.
6. HTML/SVG candidate render.
7. Screenshot critique.
8. **Only after approval:** freeze final physical geometry / scene graph.

Existing Page Spec / Scene Graph authorities remain valid, but their physical geometry fields become a **post-concept freeze**, not a pre-concept creativity constraint.

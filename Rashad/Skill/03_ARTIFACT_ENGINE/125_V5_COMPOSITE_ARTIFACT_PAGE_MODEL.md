# Composite Artifact Page Model

A consulting-grade page may include a dominant artifact plus supporting evidence structures.

## Typical allocation
- Dominant artifact: 45-65% of the page.
- Supporting evidence artifact: 15-30%.
- Implication/decision rail: 10-20%.
- Source/caveat footer: 5-10%.

## Rule
Supporting panels, cards, tables or rails are allowed only when they reinforce the dominant artifact.

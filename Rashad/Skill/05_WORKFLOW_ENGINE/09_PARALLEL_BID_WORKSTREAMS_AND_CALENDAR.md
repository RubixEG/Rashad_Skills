# Parallel Bid Workstreams & Reverse Bid Calendar

STATUS: CURRENT WORKFLOW AUTHORITY

Rashad is not a purely sequential writer. After the RFP Summary is approved, controlled workstreams run in parallel while respecting dependencies.

## Parallel workstreams
1. Compliance & submission conditions
2. Solution / methodology / workstreams
3. Team, CVs & evidence
4. Commercial / BOQ / pricing basis
5. Legal / contractual / cyber / security where relevant
6. Assumptions & clarifications
7. Arabic/English editorial & terminology
8. Artifact / visual production
9. QA / Red Team / release

## Required cross-stream synchronization
- Scope change invalidates methodology, team, timeline, commercial, risks and Executive Summary.
- Team change invalidates staffing, RACI, resource plan and pricing basis.
- Acceptance change invalidates delivery plan, risk, pricing and payment logic.
- Clarification/addendum change propagates through all affected nodes before release.

## Reverse Bid Calendar
Always back-plan from submission deadline using the actual working-day calendar.

Mandatory gates:
- RFP intake complete
- Summary approval
- Clarification decision / assumption freeze
- First full technical draft
- CV/Evidence Lock
- Commercial/Pricing Lock
- Content Freeze
- Red Team
- Translation/Arabic Editorial Freeze
- Artifact/Production Freeze
- Final Approval
- Upload/Portal Buffer
- Submission

## Cadence tiers
- **STANDARD:** 15+ working days available — full council rounds and at least one full red-team cycle.
- **COMPRESSED:** 8–14 working days — parallelize aggressively, preserve all blocking gates.
- **RAPID:** 4–7 working days — prioritize disqualification risks, scoring criteria, pricing drivers and critical artifacts; no cosmetic work before compliance/solution stability.
- **EMERGENCY:** ≤3 working days — explicit Partner decision required; release risks/assumptions must be visible internally.

Rashad calculates actual dates per opportunity. It does not invent a universal calendar date or assume weekends/holidays without the relevant working calendar.
